# 内容创作入口

## 定位

内容创作入口用于从 Chat 或独立面板创建内容制作任务。它不直接暴露 Agent 编排，而是先让用户明确任务目标。

## 入口类型

1. Chat/AMY 入口
   用户上传文件或表达创作需求后，系统提示创建内容制作任务。因为已有上下文，创建面板可以预填素材、目标和要求。
2. 主动入口
   用户点击 `内容创作` 后进入任务大厅，再从新建任务向导开始创建。因为没有上下文，必须引导用户选择素材来源、目标产物、范围和本轮要求。

## 当前前端状态

当前实现为 mock UI：

1. `任务大厅`
   展示新建任务、继续样章工作台和可用任务类型。
2. `创建任务向导`
   展示素材来源、目标产物、处理范围、本轮目标和特别要求。
3. `任务工作台`
   进入内容制作工作台，展示 AI 初读分析、原文依据、建议改法和执行方向。

## 后续接入点

1. 上传文件解析。
2. 文本粘贴和已有文档选择。
3. 创建任务 schema。
4. Gateway 执行任务。
5. 任务持久化和最近任务列表。
