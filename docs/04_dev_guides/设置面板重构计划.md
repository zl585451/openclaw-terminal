# 设置面板重构计划

> 创建：2026-04-01 | 状态：**全部完成** | 外壳：`src/components/SettingsPanel.tsx`；Tab：`src/ui/settings/tabs/*TabView.tsx`；5 个 hooks 全部接入

---

## 一、重构目标

将 1124 行的单文件设置面板拆分为：
- **4 个独立 Tab 组件**（每个 < 300 行）
- **3 个业务 Hook**（API / Nocturne / AI.library）
- **1 个外壳组件**（Tab 切换 + 底栏，< 100 行）

## 六、风险与注意事项

1. **electronAPI 类型不明确**：当前全部用 `(window as any).electronAPI`，重构时不引入类型，保持现状
2. **apply() 函数涉及所有 Tab 的状态**：需要把各 Tab 的「本地状态」通过 props 或 ref 传回外壳
3. **记忆系统轮询**：`memory` Tab 有 5 秒 interval，提取到 hook 时注意清理
4. **主题系统有新旧两套**：`SettingsContext` 里的 `THEME_PRESETS` 和 `ThemeProvider` 并存，本次不动
