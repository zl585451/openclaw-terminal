# Session: 2026-03-14 凌晨

## 🐛 OCT OptionBox 渲染问题

**问题描述**：
- `- [ ]` 格式选项被渲染两次
- 第一次：Markdown 渲染器把它变成普通列表（正文里）
- 第二次：OptionBox 组件提取并渲染成胶囊按钮（消息底部）
- 结果：同一组选项显示两次，排版混乱

**技术原因**：
- Markdown 渲染器没有跳过 `- [ ]` 格式
- OptionBox 组件从消息内容中提取选项，但原文没有隐藏
- CSS 没有处理这个冲突

**相关文件**：
- `src/components/OptionBox.tsx`
- `src/utils/markdownRenderer.ts`
- `src/styles/chat.css`

**解决方案建议**：
1. CSS 方案：隐藏 Markdown 中 `- [ ]` 格式的列表项
2. 渲染器方案：Markdown 渲染前预处理，移除已提取的选项行
3. 组件方案：OptionBox 渲染后，从正文隐藏已提取的选项
