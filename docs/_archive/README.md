## 使用规则

- 默认不要先看归档
- 只有当你需要：
  - 追溯历史决策
  - 对照旧方案
  - 查老实现是怎么设计的
  才进入 `_archive/`

- 归档内容属于 `HISTORICAL` / `REFERENCE`
- 不可直接当作当前实现真相
