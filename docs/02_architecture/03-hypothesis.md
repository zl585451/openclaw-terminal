## 3.1 假设生成（Hypothesis）

|------|------|
| 做什么 | 对复杂问题生成 2 个回复思路，选最优的 |

| 验证 | 终端看到 `[Hypothesis] 选择思路 X:` |
| 状态 | ⚠️ 需确认是否接入（import 了但可能没调用，和反馈检测同类问题） |
