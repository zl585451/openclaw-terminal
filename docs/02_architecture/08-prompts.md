# 第八层：提示词系统

| 文件 | 职责 | 更新频率 |
|------|------|----------|
| `SOUL.md` | 核心人格模板、沟通风格、禁止行为 | 低（人格变更时） |
| `AGENTS.md` | 调度规则、三角协作分工 | 中（流程优化时） |
| `USER.md` | 用户偏好档案 | 中（AI 自动更新） |
| `MEMORY.md` | 长期记忆（启动时从 Nocturne 同步） | 高（每次启动自动覆写） |
| `OCT_PROTOCOL.md` | 前端交互协议 | 高（界面迭代时） |
| `DIAGRAM_PROTOCOL.md` | 图形输出协议、结构图硬约束、聊天区/Canvas 路由规则 | 高（图形输出策略调整时） |

**注意**：存在两套目录 `docs/01_系统提示词/` 和 `docs/01_system_prompts/`，`config.PROMPTS_DIR` 决定用哪套。需确认并统一。

## 2026-04-06 结构调整说明

提示词系统已从“私人固定人格”调整为“产品默认人格 + 用户可配置层”：

- 模板文件继续使用 `{{AI_NAME}}`、`{{USER_NAME}}`
- 运行时由 `oct-gateway/config.js` 的 `config.persona` 做替换
- 设置面板可修改：
  - AI 名称
  - 用户称呼
  - 风格预设（`neutral` / `warm` / `companion`）

### 当前约束

- 发布版不要把 `AMY / 少爷` 写死进运行链路
- 私人设定只能存在于某个用户自己的配置或记忆库里
- 如需继续扩展人格，优先加到“人格配置层”，而不是直接改写公共模板为私人称谓

## 2026-04-10 图形输出补充

提示词系统新增 `DIAGRAM_PROTOCOL.md`，用于承接：

- 结构图输出协议
- 普通用户结果导向的图形路由规则
- 聊天区小图 / Canvas 图 / Markdown 文档的边界

这意味着：

- 用户通常不需要知道 `Mermaid / react-flow / echart`
- 用户提结果需求，系统内部自行决定底层图形实现
