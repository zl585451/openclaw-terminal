# 连接配置面板收纳

日期：2026-05-01

## 背景

连接配置页同时展示主对话模型、Gateway、代理、生图、图片理解、搜索与内容创作 Agent 开关，普通用户首次配置时负担过重。

## 变更

- 默认视图收敛为「主对话 AI」与「工具 AI 网关」两个入口。
- Gateway 连接、内容创作 Agent、网络代理、生图、图片理解和搜索 API 收纳进高级折叠区。
- 保留原有字段和保存行为，本次只调整信息架构，不改变实际调用链路。

## 后续

工具 AI 网关目前仍是说明入口。后续可新增统一工具模型配置，将图片、向量、后台分析、生图等专项能力逐步接入 New API。
