# 打字机流畅度优化

## 问题描述
用户反馈流式打字机效果不够流畅，即使将设置面板调到最快档位，打字速度仍然感觉较慢。

## 原因分析

通过代码审查发现以下限制导致流畅度问题：

1. **硬编码最小延迟限制** (`useTypewriter.ts:37`)
   - `Math.max(base, 30)` 强制每个字符至少有 30ms 延迟
   - 即使设置 fast 档位为 45ms，实际延迟仍在 30ms+

2. **每帧字符数限制** (`useTypewriter.ts:195`)
   - 每帧最多只处理 4 个字符
   - 限制了最大输出速率

3. **标点符号额外延迟**
   - 句号、逗号等标点有额外的停顿倍数（1.2x、0.4x 等）

## 优化措施

### 1. 降低最小延迟限制
```typescript
// 修改前
const d = Math.max(base, 30);

// 修改后
const d = Math.max(base, 5);
```

### 2. 减少标点停顿倍数
- 换行停顿：1.8x → 0.8x
- 中文句号停顿：1.2x → 0.5x
- 英文句号停顿：1.0x → 0.4x
- 逗号停顿：0.4x → 0.2x

### 3. 增加每帧最大字符数
```typescript
// 修改前
while (typedThisFrame < 4 && idx < fullLen) {
  const remain = 4 - typedThisFrame;

// 修改后
while (typedThisFrame < 8 && idx < fullLen) {
  const remain = 8 - typedThisFrame;
```

### 4. 添加极速模式
当 `baseDelayMs < 15` 时，直接显示全部内容，跳过逐字动画：
```typescript
// 极速模式：baseDelayMs < 15 时直接显示全部内容
if (baseDelayMs < 15 && idx < fullLen) {
  idx = fullLen;
  typedThisFrame = 8;
}
```

### 5. 调整速度档位
```typescript
// 修改前
const SPEED_MS: Record<StreamSpeed, number> = {
  fast: 45,    // 约13字/秒
  medium: 80,  // 约12字/秒
  slow: 140,   // 约7字/秒
};

// 修改后
const SPEED_MS: Record<StreamSpeed, number> = {
  fast: 10,    // 触发极速模式，直接显示
  medium: 60,  // 约16字/秒
  slow: 120,   // 约8字/秒
};
```

## 影响文件

- `src/hooks/useTypewriter.ts` - 核心打字机逻辑优化
- `src/contexts/SettingsContext.tsx` - 速度档位调整

## 测试建议

1. 在设置面板选择 "fast" 档位，应看到内容几乎立即完整显示
2. "medium" 档位应保持流畅但有明显打字动画
3. "slow" 档位适合需要逐字细读的场景
