# 2026-04-26 内容创作 Gateway 执行桥接

## 背景

内容创作工作台已经具备前端 mock 执行链路，但执行进度仍主要由前端触发。为了进入真实 Agent 执行前的最后一层基础设施，需要先打通前端、Electron 和 Gateway 之间的任务执行事件桥。

## 变更

1. 新增 Gateway `scriptAdapter.run.start` 请求处理。
2. 新增 `oct-gateway/script_adapter/mock_execution.js`，由 Gateway mock runner 推送 Agent 执行事件。
3. Electron preload 新增 `startScriptAdapterRun` 和 `onScriptAdapterEvent`。
4. Electron 主进程新增 `script-adapter-event` 转发，并把 `script-adapter` Gateway 事件隔离出来，不走聊天消息解析。
5. 前端新增 `gatewayExecution.ts`，封装启动执行和事件订阅。
6. 工作台“确认开工”优先走 Gateway，Gateway 不可用时降级前端 mock。
7. 新增 `内容创作Gateway执行桥接协议.md` 并更新接手指南、UI 结构规范。

## 影响

用户看到的 UI 不变，仍是“确认开工 -> 制作角色执行 -> 产物逐步生成”。内部执行来源从纯前端 mock 升级为 Gateway mock 优先，为后续接真实 Agent 和持久化铺路。

## 验证

已通过：

```powershell
npx tsc --noEmit
node -e "require('./oct-gateway/script_adapter/mock_execution'); console.log('gateway mock execution module ok')"
npm run build
```
