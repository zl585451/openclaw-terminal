# 内容创作四项确认卡交互 V2.11

## 变更摘要

- 第 2 步四张确认卡支持点击“修改”展开候选项。
- `TaskDraftConfirmItem` 增加 `id`、`options` 和 `customHint`。
- 候选项区分 AI 推荐、同类预设和 Agent 候选。
- 用户选择候选项后，卡片主值即时更新。
- 自定义输入作为补充约束保留，不直接覆盖结构化字段。

## 设计目的

让用户理解四张卡片不是普通表单，而是任务草案里的核心决策位。

系统负责预填默认方案，用户负责确认或在候选范围内修改。自由输入只用于补充边界和特殊要求，避免后台 Agent 分配失控。
