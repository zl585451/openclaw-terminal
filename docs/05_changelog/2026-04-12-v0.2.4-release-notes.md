# v0.2.4 Release Notes

## Highlights

- 引入 `Mem0` 动态记忆服务，形成「Nocturne 管身份，Mem0 管动态事实」的双轨记忆架构
- Electron 现在会自动拉起本地 `Mem0` 服务，动态记忆写入与召回不再依赖用户手动启动
- `contextBuilder` 收紧 Mem0 召回阈值到 `0.45`，并过滤“当前话题回声”，减少无关记忆和循环注入
- MiniMax `M2.7` 文本对话新增 `MINIMAX_TEMPERATURE` 配置项，日常聊天可以更偏发散而不是始终过稳

## Product Notes

- 这次版本的重点不是新增更多工作台，而是先把“AI 记住什么、怎么想起、想起后会不会打扰当前对话”做稳
- Nocturne 继续承担 boot memory、身份档案、用户长期偏好等结构化记忆
- Mem0 负责每轮对话后的动态事实抽取、语义检索和短上下文召回，失败时仍会静默回退到 Nocturne
- 如果你希望 MiniMax 在日常聊天里给出更多可能性，可以把 `MINIMAX_TEMPERATURE` 调到 `0.85` 左右
