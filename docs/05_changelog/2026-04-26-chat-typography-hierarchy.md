# 2026-04-26 聊天正文排版层级调色

## 背景

聊天区长文本回复中，标题、正文、加粗、列表项和引用块都接近同一高亮白色，导致主次难以分辨，阅读时需要逐行硬扫。

## 变更

- 收窄聊天正文列宽，降低长行阅读负担。
- 为 assistant 消息增加局部语义色变量：正文、次级正文、标题、强调、列表符号、摘要块。
- 正文从高亮白降为柔和灰白，标题与 strong 保持更高亮度。
- 列表符号改为低噪铜色，避免每个 bullet 都像强提醒。
- blockquote 改为轻量摘要块样式，使用低饱和青绿色左线与浅背景。
- 移除原先将 Markdown 各元素统一强制为 `text-primary !important` 的覆盖逻辑。
- 第二轮加强标题形状：`h1/h2/h3` 增加左侧结构线和更明确的上下间距。
- 将顶层“strong 开头”的段落转为轻量摘要块，用于承接“结论/建议”等关键判断。
- 嵌套列表降亮度、略缩小，帮助区分主 bullet 与次级说明。
- 第三轮增加 Claude 式技术对象识别：inline `code` 使用随主题可覆盖的暖铜 token 色、浅底和细边框。
- 表格改为低噪文档表：轻边框、浅表头、柔和斑马纹，并让表格内 code/ID 更醒目。

## 验证

- `npx tsc --noEmit`
