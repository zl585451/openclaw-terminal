# 内容制作工作台 V2.1 可读性优化

## Summary

- 将工作台视觉从偏开发调试态调整为偏制作统筹态。
- 调整顶部信息结构，让项目、模板和版本成为主信息，导航操作降级到右侧。
- 为左侧栏增加项目、章节导航、制作阶段分区，增强扫读路径。
- 调整阶段详情卡片，优先展示负责 Agent、阶段产物、人工复核要求，再展示 token 和运行时长等技术指标。
- 将产物预览从 JSON 调试片段改为中文制作摘要，便于制片、统筹、CV 和审校人员阅读。
- 调整 Agent 池展示方式，以 Agent 职责为主标题，以技术绑定名为副信息。
