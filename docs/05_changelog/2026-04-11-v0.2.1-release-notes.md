# v0.2.1 Release Notes

## Highlights

- 补齐主线后的 Canvas / 图表输出链路，提升结构化内容渲染稳定性
- 调整图片理解优先级：优先原生视觉，其次 MCP `understand_image`，本地视觉模型仅作为可选兜底
- 增强 MiniMax MCP 图片理解日志，便于定位安装、连接、超时与调用失败
- 修复 `mcp_*` 工具执行兜底与 `understand_image` 误判问题，减少“已识图却被判失败”的异常
- 清理项目内默认代理 / 镜像注入逻辑，MCP 子进程默认不再继承宿主里的 `HTTP_PROXY / HTTPS_PROXY / ALL_PROXY`

## Notes

- macOS 当前为未签名 DMG，首次打开时如被系统拦截，请右键应用选择“打开”，或在系统设置中手动放行。
- 本地视觉模型仍为高级可选离线兜底能力，不作为普通用户默认图片理解主路径。
