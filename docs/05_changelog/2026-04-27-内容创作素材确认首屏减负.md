# 2026-04-27 内容创作素材确认首屏减负

## 背景

新建内容任务的第一个面板同时展示素材选择、系统理解结果、后台摄入链路、确认闸门和 Agent 队列，用户进入页面后难以判断当前视点和主操作。

## 调整

1. 第 1 步标题改为“确认本次任务素材”，顶部说明从后台编排视角改为用户任务视角。
2. 中间主卡合并“当前素材、本次处理范围、字数、类型、状态”和系统理解摘要。
3. 移除第 1 步中部的重复主按钮，只保留底部固定操作栏作为唯一确认入口。
4. 第 1 步右侧栏只保留“下一步会发生什么”和“系统理解”摘要。
5. 后台摄入链路默认折叠到“查看后台处理细节”，不再与用户主流程抢视点。
6. 第 1 步不再默认展示 Agent 预分配列表，降低首屏技术噪音。
7. 二次收敛重复内容：素材库不再同时展示素材大卡和书籍下拉，章节预览不再重复书名/章节名，右侧栏不再重复展示素材、范围、字数、类型参数。
8. 修复第 3 步 AI 初读 mock 固定使用第 1 章的问题：摄入和分析 mock 现在接收当前选中的素材范围、章节标题、字数和预览片段，分析结论与问题证据会跟随用户选择更新。

## 影响

用户进入新建任务后，首屏默认只回答三件事：选了什么素材、系统理解成什么、下一步点哪里继续。
