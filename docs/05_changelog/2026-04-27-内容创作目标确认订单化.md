# 2026-04-27 内容创作目标确认订单化

## 背景

第 2 步目标和范围确认页仍像一段 AI 报告，信息密度偏高。用户将目标改成广播剧样章后，顶部说明和后续分析语境没有完全跟随变化。

## 改动

1. 第 2 步主卡改成“订单确认”结构，只展示目标、范围和下一步。
2. 用户修改工作目标后，顶部确认单、右侧摘要和后续业务分析语境同步变化。
3. 广播剧样章目标会切换到场景拆分、对白增强和音效成本语境。
4. 业务分析 mock 支持接收 `workGoal`，并按目标生成不同的分析摘要、风险项、推荐策略、后续 Agent 和交付物。
5. UI 规范补充第 2 步不得报告化、不得重复承载诊断信息的约束。

## 验证

1. `npx tsc --noEmit`
2. `npm run build`
