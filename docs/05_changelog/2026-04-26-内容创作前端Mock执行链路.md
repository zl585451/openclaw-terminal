# 2026-04-26 内容创作前端 mock 执行链路

## 背景

内容创作工作台已经具备三步确认和开工确认书，但用户点击“确认开工”后仍停留在静态确认页或高级流程占位，无法演示 Agent 团队真正开始制作、逐步产出样章成果的体验。

## 变更

1. 新增 `src/modules/script-adapter/types/execution.ts`，定义前端执行协议类型。
2. 新增 `src/modules/script-adapter/services/mockAgentExecution.ts`，模拟 5 个 Agent 串行执行。
3. 新增 `ExecutionView`、`AgentRunCard`、`ArtifactPreview` 三个工作台组件。
4. 改造 `WorkbenchView`，点击“确认开工”后切换到执行进度视图。
5. 新增执行进度、产物预览、确认闸门和取消执行的样式。
6. 更新 `内容制作工作台UI结构规范.md` 和 `00_项目接手指南.md`。

## 当前链路

1. 文本改编师生成 `AdaptedScript`。
2. 角色音统筹生成 `VoiceRoleMarkers`。
3. 演播设计师生成 `PerformanceDesign`。
4. 质检审校生成 `ReviewReport`。
5. 交付打包员生成 `DeliveryPackage`。
