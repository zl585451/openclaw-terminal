# 内容创作任务编排布局 V2.5

## Summary

- 将创建任务页从四宫格表单调整为三栏后台任务编排布局。
- 新增左侧步骤导航和任务完整度，帮助用户理解当前配置进度。
- 将素材来源、目标产物、处理范围和本轮目标收敛为中间基础配置区。
- 将本轮要求作为中间主配置区，继续保留推荐标签、边界说明和自由补充。
- 新增右侧任务摘要、即将执行 Agent 和执行边界，为后续 task schema 和 Agent 调度预览留位置。
- 新增底部固定操作栏，集中展示稍后再建、保存草稿和开始 AI 初读分析。
