# 2026-05-01 Inner Voice OS 多角色规则补强

## 背景

《夫人请卸甲》第 2 章试跑后，OS 识别已经能输出 `[角色][OS]`，但仍有三类漏判 / 归因风险：

- `来真的？` 这类短促视角疑问被保留为旁白。
- `心中嘀咕：...` 这类显式心理 cue 没有只切出冒号后的心声。
- `王管事说……真人比画像更俊美？` 这类非主角当前视角疑问需要归到三夫人。

## 变更

- 扩展 `innerVoiceSpanExtractor`：
  - 新增当前 actor 跟踪。
  - 支持显式心理 cue：`嘀咕`、`暗道`、`心想`、`腹诽`。
  - 支持短视角疑问和直接判断句：`来真的？`、`拒绝就是死！`、`接受还有活路。` 等。
  - actor 推断忽略所属 / 宾语关系，例如 `王大山给出的条件` 不会把后续 OS 错归给王大山。
- 扩展单元测试：
  - 覆盖第 2 章短疑问。
  - 覆盖 `心中嘀咕：...` 冒号后文本抽取。
  - 覆盖三夫人视角疑问。
  - 覆盖被提及角色不应抢走当前 actor。

## 验证

- `npx vitest run oct-gateway/test/innerVoiceSpanExtractor.test.js oct-gateway/test/spanScriptComposer.test.js oct-gateway/test/basicQCChecker.test.js`
- 本地抽取《夫人请卸甲》第 2 章得到 8 段 OS，关键归因：
  - `[宁默][OS] 来真的？`
  - `[宁默][OS] 拒绝就是死！ 接受还有活路。`
  - `[柳儿][OS] 王管事选的这人，真是俊的没边了……`
  - `[三夫人][OS] 王管事说……真人比画像更俊美？`
