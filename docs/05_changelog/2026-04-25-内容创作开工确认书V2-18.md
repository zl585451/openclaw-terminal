# 内容创作开工确认书 V2.18

## 背景

第三步确认后的工作台入口原本更像后台执行总览，展示了 Agent 队列、输入产物、输出产物等技术信息。对于普通用户，这些信息会造成认知负担。

## 本次调整

1. 将默认入口改为“开工确认书”视图。
2. 顶部使用“确认开工”作为主操作，突出任务已经准备好开跑。
3. 用三张核心确认卡展示做什么、做哪里、怎么改。
4. 用“谁在为你干活”展示制作角色：文本改编师、角色音统筹、演播设计师、质检审校、交付打包员。
5. 用交付清单展示用户会拿到什么。
6. 用保护条款展示不会改剧情、不会提前解释悬疑、不会乱归角色音。
7. 将 Agent ID、输入产物、输出产物和锁定依据收进“查看技术细节”折叠区。

## 影响范围

1. 前端 UI：`src/modules/script-adapter/ui/Workbench/WorkbenchView.tsx`
2. 样式：`src/modules/script-adapter/styles/scriptAdapter.module.css`
3. 规范：`docs/03_specs/内容创作工作台/内容制作工作台UI结构规范.md`

## 后续

后续可把“开工确认书”绑定真实 `TaskExecutionSheet`，并根据不同产品模板自动生成不同制作角色文案。
