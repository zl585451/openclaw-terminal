# ImageStudio 多图下载与侧栏收口

日期：2026-04-11

## 本次调整

- Image Studio 工作台新增每次生成张数选择：
  - `1`
  - `2`
  - `4`
- 工作台内新增画幅尺寸选择：
  - `1:1`
  - `16:9`
  - `9:16`
  - `4:3`
  - `3:4`
- 生图请求支持按单次请求覆盖尺寸，而不是只能依赖设置页默认值。
- 生图结果支持返回多张图片 URL。

## 下载与打开

- Electron 新增：
  - `open-external-url`
  - `download-image`
- Image Studio 主预览图新增：
  - 下载
  - 打开原图
  - 复制链接
  - 插入聊天
- 缩略图右上角增加显式下载按钮，避免只能依赖浏览器右键另存。

## 侧栏布局调整

- 主预览图缩小为更适合右侧工作台的“中图”模式，不再与聊天区的大图展示重复争抢空间。
- 下方改为 2 列缩略图浏览，更适合多图场景下选图。

## 设计取舍

- 仍然默认只把第一张结果自动插入聊天，避免多图场景下一次往主聊天流灌入 4 张图片导致刷屏。
- 更完整的多图聊天卡片可以后续再做。
