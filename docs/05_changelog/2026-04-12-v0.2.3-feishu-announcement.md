🚀 OCT v0.2.3 发布 | Canvas 画图体验继续优化

各位好，OCT v0.2.3 现已正式发布。

如果你刚进群，可以把 OCT 理解成一个“能聊天、能调用工具、还能直接把结果做出来”的 AI 桌面客户端。

它不只是回答你一句话，而是可以把结果直接落下来给你看：
• 聊天问答
• 流程图 / 架构图 / 数据图表
• 文档草稿 / 代码草稿
• 图片生成
• 音乐生成
• 工具调用和任务执行

这次更新最主要就是继续优化 Canvas，也就是右侧那个专门用来看图、看表、看文档结果的区域。

【这次更新了什么】
• Canvas 打开更稳了：图表、流程图、结构图、文档结果更容易正确显示
• 画图体验更好了：React Flow 连线、层级、排版比之前更清楚
• 容错更强了：有些模型输出不太规范时，Mermaid / ECharts 也更容易直接渲染成功
• 多结果切换更顺了：现在在同一个工作区里切换文档、图表、流程图会更稳定

【OCT 和 OpenClaw 有什么不一样】
• OpenClaw 更像底层能力和命令体系
• OCT 是面向普通用户的桌面成品版，更强调“直接拿来用”
• 你不用自己拼环境，也不用记太多命令
• 聊天、Canvas、图片、音乐、工具执行都在一个桌面窗口里完成

简单说：
OpenClaw 更偏底层能力，
OCT 更偏真正可用的桌面助手。
