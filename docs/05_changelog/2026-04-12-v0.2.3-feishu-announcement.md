# v0.2.3 飞书群公告

各位好，`OCT OpenClaw Terminal v0.2.3` 现已发布。

这次更新的重点不是单点修补，而是把原来的 `Canvas` 正式升级成了 `Workbench` 基础子系统，为后续的文本工作台、图表工作台、代码工作台继续演进打好了底层结构。

本次重点更新：

- `Canvas -> Workbench`：聊天链路、工作台链路、插件注册层完成拆层
- 新增 `workbenchEvent / workbenchContext` 主语义，旧 `canvas*` 字段保留兼容
- React Flow 排版增强：连线、层级、节点尺寸估算、大图自适应间距都有补强
- Mermaid / ECharts 容错增强，模型输出不规范时也更容易渲染成功
- 多 artifact 工作流更稳：Markdown、ECharts、Mermaid、React Flow 可以在同一工作台切换

下载方式：

- GitHub Releases: `https://github.com/zl585451/openclaw-terminal/releases/tag/v0.2.3`

补充说明：

- 这次已经把主线工作台架构拆好了，明天会继续做 Workbench 的可用性优化，重点会放在大图拆分策略、React Flow 表达质量和后续文本工作台能力上。
