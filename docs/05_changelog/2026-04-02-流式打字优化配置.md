# 2026-04-02 流式打字优化配置

## 问题
流式打字出现"一坨坨"现象，不流畅。

## 根因
Gateway 的流合并配置太保守：`max_chars: 8` 导致每攒够 8 字符才推一次。

## 修改

### 1. oct-gateway/config.json
```json
"stream_merge": {
  "min_chars": 1,
  "max_chars": 2,   // 8 → 2
  "idle_ms": 16     // 5 → 16
}
```

### 2. oct-gateway/config.js
```javascript
const def = { min_chars: 1, max_chars: 2, idle_ms: 16 };
// 原来是: { min_chars: 1, max_chars: 3, idle_ms: 30 }
```

## 参数说明
- `max_chars: 2` - 每 2 个字符就推一次（原来是 8）
- `idle_ms: 16` - 16ms 没新 token 就推（约 60fps）

## 预期效果
流式打字从"一坨坨"变成"丝滑逐字"，类似 Claude 的效果。

## 重启步骤
```bash
cd oct-gateway
node --watch index.js
```
