# 2026-04-24 Script Role List Toggle

## Summary

- Added a lightweight role list toggle to the script toolbar.

## What Changed

- The script toolbar now includes a `角色列表` toggle that opens a compact list instead of restoring the old full chip wall.
- The list shows the current document's recognized role library with color markers.
- Roles currently detected in the active chapter are marked as `当前章`.

## User Impact

- Users can inspect recognized role names and compare them with current chapter usage without overwhelming the layout.
- This makes it easier to spot recognition errors before adjusting the detection logic.
