# 2026-04-19 移除录音转文字（ASR）链路

## 背景
- 录音输入功能使用率低，且经常因 API Key 配置异常造成 401 报错。
- 为减少输入链路复杂度，本次将 ASR 从产品主链路中移除，仅保留文本输入与 TTS 输出。

## 代码变更
- 删除聊天输入区录音按钮、录音状态与音频编码逻辑：`src/ui/chat/ChatInput.tsx`
- 删除 Electron ASR IPC：`electron/main.ts` 中 `asr-transcribe` handler
- 删除渲染进程 ASR 暴露：`electron/preload.ts` 中 `asrTranscribe`
- 删除前端类型声明：`src/vite-env.d.ts` 中 `asrTranscribe`
- 删除 capability 系统里的 ASR 能力：
  - `src/core/capabilities/types.ts`
  - `src/core/capabilities/providers.ts`
  - `src/ui/onboarding/CapabilitySetupDrawer.tsx`
- 清理录音按钮样式：`src/styles/ChatTab.css`

## 文档回填
- AI 入口层：
  - `docs/00_ai_entry/audio-entry.md`（音频链路从三条收敛为两条）
  - `docs/00_ai_entry/README.md`
  - `docs/00_ai_entry/bug-triage.md`
- 架构层：
  - `docs/02_architecture/07-electron.md`（7.6 调整为仅 TTS）
  - `docs/02_architecture/FEATURE_MAP.md`

## 影响
- 聊天输入区不再提供录音转文字入口。
- 语音相关能力仅保留打字音效与 TTS。
- 旧 ASR 配置项（如 `DASHSCOPE_API_KEY` 对 ASR 的用途）不再被该功能消费。
