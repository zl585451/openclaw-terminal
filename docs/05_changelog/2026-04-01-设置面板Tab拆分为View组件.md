# 2026-04-01 设置面板 Tab 拆分为 View 组件

## 变更

- 将 `SettingsPanel.tsx` 内四个 Tab 的正文 JSX 抽到 `src/ui/settings/tabs/` 下的 **presentational** 组件：`ConnectionTabView`、`InterfaceTabView`、`MemoryTabView`、`AdvancedTabView`。
- 状态、`apply()`、Gateway 保存、记忆 Tab 5 秒轮询等逻辑仍保留在 `SettingsPanel.tsx`；外壳仍为 `settings-overlay` + `settings-panel settings-panel-large`，页脚「应用」行为不变。
- 删除已废弃的 hook 占位 Tab：`ConnectionTab.tsx`、`InterfaceTab.tsx`、`MemoryTab.tsx`、`AdvancedTab.tsx`；`tabs/index.ts` 改为导出上述 `*View` 组件。

## 原因

降低 `SettingsPanel.tsx` 体积、与 UI 分层（`src/ui/` 组合展示）一致，同时避免此前误用 `settings-modal` 或页脚只关不存等问题再次出现。
