# 内容创作摄入链路 MVP V2.10

## 变更摘要

- 新增本地 mock 摄入业务层 `runMockTaskIntake`。
- 支持从第 1 步确认素材后模拟执行后台链路。
- 右侧后台摄入链路可以展示 pending、running、done 状态。
- 第 2 步方案确认单改为读取 `IntakeResult`，不再直接读取散落常量。

## 当前链路

1. 用户点击“确认素材，生成任务方案”。
2. 系统进入 `running` 状态。
3. mock executor 依次推进 RawAsset、文本抽取、SourceDocument、SourceProfile、TaskDraft。
4. 完成后生成 `IntakeResult`。
5. UI 自动回填素材参数、AI 推荐方案、确认项和 Agent 队列。

## 设计边界

- 当前不接真实上传。
- 当前不接 Gateway。
- 当前不调用真实 AI。
- 当前目标是让创建任务链路可试跑，并沉淀未来真实后台需要返回的数据结构。
