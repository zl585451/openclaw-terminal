# 内容创作工作台阶段 2：行协议解析与合并

日期：2026-04-30

## 变更

- 新增 `oct-gateway/script_adapter/lineProtocolParser.js`，将 Text Rewriter 的行协议输出解析为冻结的 `AdaptedScriptPayload` 结构。
- `textRewriterAgent.js` 的解析入口从 JSON 解析切换为行协议解析，保留旧 `extractJsonObject()` 作为兼容辅助但不再走主链路。
- Text Rewriter 请求不再强制 `response_format=json_object`，为阶段 3 接入冻结行协议 prompt 做准备。
- chunked 合并逻辑改为至少一个 chunk 成功时返回合并结果；失败 chunk 以旁白占位 segment 保留，全部失败才抛错。
- 新增 parser 单元测试，并用阶段 1 round9 三份真实输出验证解析成功率、segmentId 连续性和 speaker trim。
