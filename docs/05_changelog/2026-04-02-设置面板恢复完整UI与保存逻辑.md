# 2026-04-02 设置面板恢复完整 UI 与保存逻辑

## 背景

短暂将 `SettingsPanel.tsx` 改为「外壳 + Tab」时出现问题：

1. **样式**：使用了 CSS 中不存在的 `settings-modal`，而样式表只定义了 `settings-panel` / `settings-panel-large`，导致面板无背景、无固定尺寸、与聊天层叠。
2. **保存**：底部按钮仅 `onClose()`，未执行原有的 `apply()`（`saveApiKeys`、`setSettings`、`setPermissions`、截图快捷键、localStorage 与字体 CSS 变量等）。

## 处理

- 恢复与提交 `e6a1582`（「修复：ConnectionTab 添加 MiniMax 支持…」）一致的 **`src/components/SettingsPanel.tsx`**：完整 Tab 内联 UI、`settings-panel settings-panel-large`、**「应用」** 调用 `apply()`。
- 同步恢复误改的 **`useAdvancedSettings.ts`**、**`useScreenshotShortcut.ts`**、**`InterfaceTab.tsx`**，避免其他引用处行为异常。

## 备忘（后续若再拆 Tab）

- 外层容器 class 必须与 `SettingsPanel.css` 一致：`settings-overlay` + `settings-panel settings-panel-large`。
- 全局「应用」须保留或等价实现原有 `apply()` 行为，不可仅关闭弹窗。
