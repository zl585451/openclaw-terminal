# 2026-04-19 MCP 面板改为纯手动添加

## 变更背景
- 用户反馈 MCP 面板的模板预设过多，干扰配置。
- 目标是保留连接状态可见性，同时简化新增流程。

## 代码变更
- `src/ui/settings/tabs/McpTabView.tsx`
  - 删除预设模板列表（`MCP_PRESETS`）与分类卡片区。
  - 删除“从预设一键填充”交互。
  - 保留“已连接的服务器”展示区（名称、连接状态、命令、可用工具、删除）。
  - 保留并固定展示“手动添加 MCP 服务器”表单。
  - 增加可折叠的简短安装提示（示例命令）。

## 行为说明
- 手动添加并连接成功后，服务器会显示在“已连接的服务器”卡片区。
- 非 `minimax` 的自定义服务显示默认图标 `🔧`，但状态与信息展示一致。
