# 2026-04-25 内容创作双确认流程定版

## 变更摘要

本次将内容创作任务创建页从“后台表单配置”推进为“双确认闸门”模式，为下一阶段 Agent 和后台业务逻辑接入建立基线。

## 前端变更

1. 创建任务页改为两个主步骤：确认素材、确认执行。
2. 第一步展示素材来源、素材参数、文件解析和 Agent 预分配。
3. 第二步展示目标产物、处理范围、本轮目标、任务要求和即将锁定的 Agent 团队。
4. 底部操作栏改为围绕确认闸门表达当前状态。
5. 右侧任务摘要增加当前闸门状态。

## 文档变更

1. 新增 `内容创作任务创建双确认流程`。
2. 新增 `内容创作任务对象模型`。
3. 新增 `内容创作 Agent 分层与确认闸门`。
4. 更新内容制作工作台 UI 结构规范至 v1.1。
5. 更新内容创作入口文档，明确 Chat/AMY 入口和主动入口都必须经过双确认流程。

## 后续建议

下一步进入后台设计阶段，优先定义任务创建 schema、SourceDocument 解析服务、Agent 注册表和 ExecutionGate 状态机。
