# 2026-04-02 自定义 OpenAI 兼容服务支持

## 功能描述

添加对自定义 OpenAI 兼容 API 的支持，用户可以填入任意 OpenAI 格式的 API 地址和模型名称。

## 使用场景

- 使用第三方 OpenAI 代理服务
- 使用自托管的 OpenAI 兼容 API
- 使用其他平台的 OpenAI 兼容接口（如 Claude、Gemini 等）

## 配置方法

1. 打开 **设置 → 连接设置**
2. 选择 **AI 服务商** 为 **"自定义 OpenAI 兼容服务"**
3. 填写以下信息：
   - **API Key**：你的自定义 API Key
   - **Base URL**：OpenAI 兼容格式的 API 地址（如 `https://api.example.com/v1`）
   - **自定义模型名称**：任意模型名称（如 `gpt-4o-mini`、`claude-3-sonnet` 等）

## 技术改动

### Gateway (oct-gateway/)

- **providers.js**：添加 `custom` provider，支持自定义模型输入
- **config.js**：添加 `CUSTOM_API_KEY`、`CUSTOM_BASE_URL`、`CUSTOM_MODEL` 支持

### Electron (electron/)

- **main.ts**：支持保存和读取自定义配置
- **preload.ts**：添加类型定义

### Frontend (src/)

- **ConnectionTabView.tsx**：添加自定义模型输入框和 Base URL 输入
- **useApiKeys.ts**：支持自定义配置的状态管理

## 配置示例

```json
{
  "OCT_PROVIDER": "custom",
  "OCT_MODEL": "gpt-4o-mini",
  "CUSTOM_MODEL": "gpt-4o-mini",
  "CUSTOM_API_KEY": "sk-your-key",
  "CUSTOM_BASE_URL": "https://api.openai-proxy.com/v1"
}
```

## 注意事项

1. Base URL 必须以 `/v1` 结尾，符合 OpenAI API 格式
2. 自定义模型支持工具调用（如果 API 支持）
3. 流式输出功能取决于 API 是否支持 SSE
4. 保存配置后会自动重启 Gateway 生效
