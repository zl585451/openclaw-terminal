# 内容创作任务方案确认单 V2.9

## 变更摘要

- 将创建任务第 2 步从完整配置表单调整为“AI 推荐执行方案确认单”。
- 主路径只保留目标产物、处理范围、改动权限、下一步 Agent 四个确认项。
- 将目标、范围、本轮动作等细项降级到“微调设置”，避免首屏认知负担过重。
- 保留补充要求、推荐标签和执行边界，作为任务方案的附加说明。

## 设计原因

第 2 步之前同时展示 AI 初步判断、推荐方案、目标配置、范围配置、本轮要求和 Agent 队列，用户需要先理解系统结构才能继续操作。

V2.9 改为先给出一张可确认的任务方案，让用户只判断“这个方案能不能执行”。高级配置仍保留，但不再阻挡主流程。
