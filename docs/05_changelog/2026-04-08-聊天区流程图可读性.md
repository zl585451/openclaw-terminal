# 2026-04-08 — 聊天区 Mermaid 流程图可读性

## 背景

横向（LR）流程图在聊天预览里常被压成极扁的一条，节点文字难以辨认：此前 compact 模式按「同时塞进固定宽高」缩小，且 `scale` 上限为 1，宽图高度被拖垮。

## 改动

- `src/components/canvas/MermaidRenderer.tsx`：`polishSvg` 在聊天 compact 下保证最小渲染高度（约 236px），允许在 `maxScale` 内放大；略提高流程图 `nodeSpacing` / `rankSpacing`；`CACHE_VERSION` 升至 `v6`。
- `src/components/CanvasPanel.css`：compact 舞台横向可滚动、`min-height`/`max-height` 约束；新增 `canvas-mermaid-stage--compact-inner` 使窄图居中、宽图可横向滚动浏览。
- `MermaidRenderer`：compact 时在舞台内增加一层 wrapper 以配合上述布局。

## 用户侧效果

聊天里的简单流程图更高、字更大；特别宽的图可在卡片内左右滑动查看，或仍使用 Open 进入 Canvas。
