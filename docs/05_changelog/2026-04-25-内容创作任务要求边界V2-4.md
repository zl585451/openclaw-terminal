# 内容创作任务要求边界 V2.4

## Summary

- 将创建任务向导中的 `填写本轮要求` 从单一自由文本框升级为有边界的任务说明区。
- 新增推荐要求标签，帮助用户快速选择常见改编边界和输出要求。
- 新增“应该写 / 不要写 / 系统会处理”说明，降低用户不知道怎么填的认知负担。
- 新增执行边界提示，明确自由输入会先整理成任务摘要，无关内容不会直接进入执行链。
- 新增建议字数和过短/过长提示。
- 更新 UI 规范，明确用户补充要求与 Agent 执行指令之间需要有结构化整理层。
