# 内容创作工作台执行单视图 V2.16

## 背景

第三步确认修改策略后，用户进入工作台时不应再次面对“确认分析、补充要求、决定怎么改”的页面。该阶段的心智应从“定任务”切换为“看执行”。

## 本次调整

1. 将工作台默认页改为任务执行总览。
2. 顶部展示任务执行单已生成，并提供启动制作、查看队列按钮。
3. 展示本轮已锁定的产品目标、处理范围、修改策略和人工复核点。
4. 展示 Agent 执行队列，包括阶段状态、绑定 Agent、输入产物、输出产物和人工复核要求。
5. 展示本轮预期交付产物和已锁定依据。
6. 移除默认页中的二次确认式任务 textarea 和“采纳建议”语义。

## 影响范围

1. 前端 UI：`src/modules/script-adapter/ui/Workbench/WorkbenchView.tsx`
2. 样式：`src/modules/script-adapter/styles/scriptAdapter.module.css`
3. 规范：`docs/03_specs/内容创作工作台/内容制作工作台UI结构规范.md`

## 后续

后续接真实业务时，第三步确认后应生成 `TaskExecutionSheet`，工作台默认读取该对象渲染执行单、Agent 队列和产物预期。
