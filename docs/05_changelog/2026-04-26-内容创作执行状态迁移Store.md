# 2026-04-26 内容创作执行状态迁移 Store

## 背景

Week1 Track A 首版为了快速跑通前端 mock 闭环，将 `executionSheet` 放在 `WorkbenchView` 组件内。该方案能演示开工后 Agent 执行进度，但不适合后续跨视图同步和 Gateway 异步执行。

## 变更

1. 在 `scriptAdapterStore` 中新增 `executionSheets`。
2. 在 `scriptAdapterActions` 中新增执行状态相关 action。
3. `WorkbenchView` 改为从 store 读取当前项目的 `TaskExecutionSheet`。
4. mock pipeline 回调改为通过 action 更新 `AgentRun`、`ArtifactEnvelope` 和 `ReviewGate`。
5. `ExecutionView` 保持展示组件职责，不承担状态管理。

## 影响

执行状态现在可以被工作台以外的后续视图复用，也更接近 Gateway 状态机的接入方式。

## 验证

已通过：

```powershell
npx tsc --noEmit
npm run build
```
