# v0.2.2 Release Notes

## Highlights

- 新增 `Image Studio` 独立生图工作台，生图请求与聊天主链路解耦
- 支持在侧栏直接生成、预览、下载、打开原图，并把结果插回聊天记录
- AMY 提示词优化回填做了清洗，兼容部分模型输出的 CoT / 说明文字
- 生图控制面板改为更通用的跨供应商语义：画幅、风格倾向、质量、Seed、提示词优化、水印、高级尺寸
- 在图生图验证不稳定后，主动下线图生图，只保留稳定的文生图能力
- Image Studio 新增显式 `返回聊天` 按钮，并支持 `Esc` 直接退出

## Product Notes

- `Image Studio` 当前定位为稳定文生图工作台，不再承诺图生图的一致性控制
- 生成结果会同时留存在侧栏预览区，并可按需插入聊天流
- 当前主面板优先保留跨供应商稳定语义，供应商差异由网关适配层处理
