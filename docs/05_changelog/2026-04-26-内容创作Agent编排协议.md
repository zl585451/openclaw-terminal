# 2026-04-26 内容创作 Agent 编排协议

## 背景

内容创作工作台已经具备三步确认 UI、开工确认书、任务对象模型和多人演播有声书业务规则，但缺少一份把 Agent 注册、工作包、产物信封、确认闸门和执行状态机串起来的通用协议。

如果不先补齐编排协议，后续 Gateway 接入、真实 Agent 调用、图书馆模块复用和广播剧团队扩展都会缺少共同语言。

## 关键结论

1. MVP 阶段默认串行执行，先保证产物链稳定。
2. Agent 不共享大上下文，而是读取最小必要 `AgentWorkPacket`。
3. 每个 Agent 输出都应包装为 `ArtifactEnvelope`。
4. 人工确认统一使用 `ReviewGate`。
5. 图书馆模块可以复用基础分析和入库类 Agent，但不应直接调用深度改编和演播设计 Agent。
