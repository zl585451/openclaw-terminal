# fix: 提高 Mem0 相关性过滤阈值 + 防循环注入

**日期**：2026-04-12  
**文件**：`oct-gateway/runtime/contextBuilder.js`

## 问题 1：阈值过低

Mem0 搜索结果过滤阈值为 `score < 0.3`，bge-m3 余弦相似度 0.3 几乎等于"语义不相关"，导致大量无关记忆被注入 `[相关记忆]` 块，AMY 感知为噪音。

**修复**：将 `score < 0.3` 改为 `score < 0.45`。

## 问题 2：循环注入

用户当前在讨论"Mem0 噪音"→ 这条对话被 Mem0 存储 → 下次搜索命中 → 把"正在讨论的话题本身"当背景记忆塞回来，形成循环。

**修复**：在 Mem0 结果遍历时，计算 memory 文本与当前 `userMessage` 的词重叠率，若 >45% 则认定为"本轮话题回声"，跳过不注入。

## bge-m3 score 参考

- < 0.3 ：基本不相关
- 0.3–0.45：弱相关，容易引入噪音
- > 0.45 ：语义有实质关联
