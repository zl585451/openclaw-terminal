# 2026-04-02 MiniMax 流式思考标签与模型能力

## 摘要

为独立 MiniMax 模型（`MiniMax-M2.7` / `M2.5-standalone` / `M2.1` / `M2` 及对应 highspeed）在 `MODEL_REGISTRY` 中开启 `supportsThinking: true`，并声明 `thinkingFormat: 'think_tags'`。在 `ai.js` 流式输出中解析 `<redacted_thinking>...</redacted_thinking>`，实时转换为 `[cot]...[/cot]`，供前端 CoT 展示；非该格式的模型逻辑不变。

## 涉及文件

- `oct-gateway/config.js`：上述 MiniMax 条目 + 未知模型默认能力增加 `thinkingFormat: null`。
- `oct-gateway/ai.js`：`caps` 合并时带上 `supportsThinking` / `thinkingFormat`；`processContentChunk` + `flushThinkPending`；标签跳过长度使用 `OPEN_THINK.length` / `CLOSE_THINK.length`（完整标签名，非错误 slice 偏移）。

## 说明

百炼路由下的 `MiniMax-M2.5` 条目未改；仅 `provider: 'minimax'` 的独立模型走 `think_tags` 解析。
