# 2026-04-26 聊天外壳圆角与控件语气统一

## 背景

聊天正文已经转向低噪文档阅读风格后，外层控件仍混用终端方角、网页 pill、大圆角气泡，导致界面像“Claude 式正文 + 旧终端 HUD”的半成品拼接。

## 变更

- 将用户气泡、输入框、发送按钮统一到 8px 半径。
- 将文件/附件/快捷按钮统一到 4px 半径，保留工具按钮感。
- 将底部能力 chip 与回复选项 pill 从胶囊形收敛为 6px 小圆角。
- 降低底部能力条文字、图标和 hover 背景的存在感，让对话正文成为视觉主轴。
- 保持表格、摘要块和 inline code 的小圆角系统一致。

## 验证

- `npx tsc --noEmit`
