🚀 OCT v0.2.4 发布 | Nocturne + Mem0 双轨记忆正式上线

各位好，OCT v0.2.4 现已正式发布。

这次更新我们没有继续堆很多表层功能，而是先把一个更底层、但实际使用时非常影响体验的问题补上了：
AI 到底记住什么，什么时候想起来，想起来之后会不会打扰你当前正在聊的话题。

【这次更新了什么】
• 动态记忆升级：新增 Mem0 服务，专门负责从对话里提取事实和做语义召回
• 角色记忆保留：Nocturne 继续负责身份、偏好、长期档案等 boot memory
• 噪音更少了：Mem0 召回阈值提高，并过滤“当前正在讨论的话题本身”，减少循环注入
• 对话更灵活了：MiniMax M2.7 新增温度可配置，想要更发散的聊天风格可以直接调高

【为什么这次值得更新】
• 以前 AI 容易把一些弱相关内容也塞回上下文，像“想起了什么”，但其实并不重要
• 现在会更偏向召回真正和当前问题有关的事实
• 即使 Mem0 不可用，也不会把主对话链打断，系统会静默降级回 Nocturne

【当前版本说明】
• Windows 安装包会优先更新
• macOS / Linux 资产继续沿 Release 页面分发
• macOS 当前仍为未签名 DMG，首次打开如被拦截，请右键应用选择“打开”
