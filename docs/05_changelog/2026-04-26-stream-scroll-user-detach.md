# 2026-04-26 流式输出滚轮脱离优化

## 背景

流式输出期间，用户滚轮上滚查看历史时，聊天区会被锚点补偿逻辑拉回，表现为“滚一下又弹回”。根因是本轮用户消息的顶部锚点在流式增量渲染期间仍保持 locked，`reconcile()` 会继续调整 `scrollTop`。

## 变更

- `ScrollAnchor.onUserScroll()` 增加滚动方向/距离参数。
- 用户明确上滚超过阈值时释放锚点锁，后续流式 `reconcile()` 不再抢占用户滚动位置。
- 小幅滚动噪声仍保留锚点锁，避免触控板轻微抖动误触发。
- 用户脱离锚点后立即显示回到底部按钮，便于重新追踪最新输出。
- 增加单元测试覆盖小幅滚动、主动上滚释放、释放后不再补偿滚动位置。

## 影响

默认发送后的顶置体验保持不变；只有用户在流式输出期间主动上滚时，聊天区会进入用户优先的阅读状态，更接近 Claude / ChatGPT 的滚动体验。
