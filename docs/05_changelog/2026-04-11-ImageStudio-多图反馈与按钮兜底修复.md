# ImageStudio 多图反馈与按钮兜底修复

日期：2026-04-11

## 修复内容

- Image Studio 结果区不再把当前主预览图重复显示在下方缩略图区，避免“看起来像生成了两张相同图片”的误解。
- 对多图结果做 URL 去重，避免服务端重复返回同一张 URL 时前端重复堆叠。
- 当用户请求 `2` 或 `4` 张，但服务端实际只返回更少图片时，状态文案会明确显示：
  - 例如：`生成完成，服务端返回 1/2 张`

## 按钮兜底

- `打开原图`：
  - 优先走 Electron `open-external-url`
  - 失败时回退到浏览器 `window.open`
- `下载`：
  - 优先走 Electron `download-image`
  - 若桌面下载能力未触发，则回退到 `<a download>` 方式
- `复制链接`：
  - 优先走 `navigator.clipboard`
  - 失败时回退到 `execCommand('copy')`

## 目的

- 避免“按钮看起来没反应”的黑箱体验
- 即使桌面层能力没有及时生效，也尽量给用户一个可感知的退路和状态反馈
