# 2026-04-11 ImageStudio 图生图下线

## 本次调整

- Image Studio 暂时移除图生图模式，只保留稳定的文生图工作流。
- 前端去掉图生图切换、参考图 URL、本地参考图拖拽与上传入口。
- `image-generate` IPC 与 Gateway 协议回到文生图主链路，不再在主面板暴露参考图参数。

## 调整原因

- 现阶段图生图结果存在较大的不确定性，难以稳定保证主体一致性与风格延续。
- 问题可能来自模型能力、服务商接口行为、参考图理解机制或提示词控制粒度，短期内难以可靠收敛。
- 为避免一个不稳定能力拖累整体体验，先收口到可交付的文生图能力。

## 产品决策

- 先把 Image Studio 定义为“稳定文生图工作台”。
- 后续如需重启图生图，将优先基于明确的供应商能力说明、参考图约束策略和更严格的回归验证重新设计。
