# 2026-04-27 内容创作开工确认页减负与交付窗口

## 背景

内容制作工作台的最后确认页同时展示开工确认、批次进度、批次历史、Agent 队列、交付清单和导出按钮，用户无法判断当前应先确认开工还是查看交付。

## 调整

1. 开工前不再自动选中最近 completed 批次，避免旧批次进度抢占最终确认页。
2. 最终确认页只保留一个主确认按钮，预算卡不再重复放置同等级启动按钮。
3. “查看高级流程”改为“返回修改方案”，弱化开发调试语义。
4. 批次历史、制作角色和详细交付说明仅在已有当前批次后展示。
5. 批次进度面板新增高对比度状态区：进度、失败数、费用、状态和进度条。
6. 批次完成后在进度面板顶部显示交付窗口，集中提供 Word DOCX 和 Markdown 导出入口。
7. 工作台改为同页三状态：开工前只显示确认书，开工中显示状态横幅和批次进度，完成后以交付窗口为主视觉。
8. 开工前顶部摘要不再重复展示字数，字数和费用集中在预算卡内展示一次。
9. 批次历史、制作角色、交付清单和保护条款改为折叠详情，不再默认拉长页面。

## 影响

开工前页面聚焦“方案是否正确、预算是否可接受、是否确认开工”。开工后才进入执行/交付视图，完成后用户可以从交付窗口直接导出产物。
