# 2026-04-25 内容创作素材归属驱动目标候选 V2.14

## 变更摘要

- 在 mock 摄入结果中新增 `SourceProfile`，用于表达素材归属、结构判断、适配方向和不建议方向。
- 第二步目标候选改为基于素材归属生成，不再表达全量产品模板。
- 第二步移除自由补充说明大文本框，只保留目标和范围确认卡。
- UI 新增“基于素材归属生成的可选方向”和“不提供方向”提示。
- 文档明确：识别为论文时不应出现多人演播有声书等小说类选项。

## 设计结论

- 第一步负责“看懂这是什么文本”。
- 第二步负责“基于这个文本能做什么、做哪一段”。
- 第三步以后才负责“怎么改、改到什么深度”。
