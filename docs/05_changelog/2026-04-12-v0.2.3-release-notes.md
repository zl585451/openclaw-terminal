# v0.2.3 Release Notes

## Highlights

- `Canvas` 基础架构升级为 `Workbench` 子系统，工作台不再只是聊天附属抽屉
- 聊天链路、工作台链路、插件注册层完成拆分，后续可继续接文本工作台、图表工作台、代码工作台
- 新增 `workbenchEvent / workbenchContext` 主语义，保留 `canvasEvent / canvasContext` 兼容层，降低迁移风险
- React Flow 大图排版增强：补齐连线、层级、节点尺寸估算和复杂图自适应间距
- Mermaid、ECharts 渲染容错增强，模型输出不规范时也更容易正确打开到工作台

## Product Notes

- 当前 `Workbench` 已具备多 artifact 宿主能力，支持 Markdown、ECharts、Mermaid、React Flow、代码等内容在同一工作台切换
- `Canvas` 命名仍保留兼容入口，但新能力以后统一沿 `Workbench` 语义演进
- React Flow 在节点较多时仍建议采用“总览图 + 子图展开”的表达方式，单图推荐控制在 `12` 个节点以内
