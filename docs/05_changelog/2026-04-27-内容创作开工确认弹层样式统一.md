# 2026-04-27 内容创作开工确认弹层样式统一

## 背景

开工确认使用浏览器原生 `window.confirm()`，视觉上跳出当前工作台，且大批量真实试产、BGM/SFX 高成本等风险会连续弹系统确认框。

## 改动

1. 将开工确认替换为页面内弹层，沿用工作台浅绿、米色、圆角卡片风格。
2. 弹层集中展示素材范围、章节、字数、耗时、费用、试产模式和交付项。
3. 大批量真实试产和 BGM/SFX 高成本警告合并到同一个弹层中。
4. 保留绿色主按钮和次级取消按钮，避免用户离开当前页面心智。

## 验证

1. `npx tsc --noEmit`
2. `npm run build`
