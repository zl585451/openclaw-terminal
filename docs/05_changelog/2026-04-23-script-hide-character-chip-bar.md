# 2026-04-23 Script Hide Character Chip Bar

## Summary

- Temporarily removed the character/name chip cluster from the script editor toolbar.

## What Changed

- The script toolbar now keeps only the right-side editing controls.
- Character filter chips and inline color editing UI are hidden for now to avoid oversized layouts when prose text is manually switched into `script` view.

## User Impact

- Novels or prose content previewed in `script` mode no longer get visually overwhelmed by a huge name/category chip wall.
- Character grouping behavior can be redesigned later without blocking script-view experimentation now.
