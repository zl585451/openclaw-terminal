# 2026-04-29 工作台开工页移除演示模式

## 背景

任务创建链路已经接入真实状态机后，工作台开工页仍保留“模拟演示 / 真实 Agent”切换，以及左侧“人工复核”第 5 步，容易让用户误解当前仍是 demo 流程或存在阻塞复核闸门。

## 改动

- 移除工作台顶部“单章执行模式”切换。
- 移除开工确认页“试产模式”配置块。
- 批次启动固定为 `executionMode: real` 与 `realAgents: all`。
- 左侧任务步骤移除第 5 步“人工复核”。
- 开工确认弹窗将“试产模式”改为“执行方式：真实 Agent 制作”。
- 历史 Stage 详情中的“人工复核”指标改为非阻塞“质量检查”。

- `npx tsc -p tsconfig.electron.json --noEmit`
