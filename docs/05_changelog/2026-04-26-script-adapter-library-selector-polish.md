# 内容创作工作台书库选择器可读性修复

- 日期：2026-04-26
- 范围：`WorkbenchView`、`scriptAdapter.module.css`

## 问题

Week 4 接入书库选择器后，组件被挤进开工确认卡右侧窄栏，导致：

- 下拉框宽度不足，文字被截断且难读
- 标签与错误文案对比度过低
- 小屏或窄窗口下控件容易贴边、出屏

## 修复

- 将开工确认卡拆为“左侧主内容 + 右侧操作区”，书库选择器与测试原文输入统一放回左侧主列。
- 提升书库选择器和测试输入区的字体对比度、边框、背景层次与 focus 态。
- 调整下拉框栅格列宽与换行规则，小于 900px 时自动纵向堆叠。
- 来源 badge 支持多行换行，避免长书名溢出。

## 验证

- `npx tsc --noEmit`
- `npm run build`
