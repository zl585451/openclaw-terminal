# ImageStudio 通用面板重构

日期：2026-04-11

## 调整目标

- 不再把 Image Studio 主面板设计成 MiniMax 专用控制台。
- 改为“跨供应商稳定语义 + 网关适配层”的结构，便于后续接入其他图像供应商。

## 主面板保留

- 提示词
- 负向提示词
- 文生图 / 图生图
- 画幅
- 风格倾向
- 质量
- 随机种子 `seed`
- 自动优化提示词
- 水印

## 高级区

- 自定义 `width / height`
- 说明不同供应商可能忽略该项

## 移除

- 从主面板移除“多图生成”入口
- 不再把供应商特有能力直接当作通用 UI 假设

## 网关适配

- MiniMax：
  - 画幅 -> `aspect_ratio`
  - `seed`
  - `prompt_optimizer`
  - `aigc_watermark`
  - 自定义宽高 -> `width/height`
- OpenAI 兼容：
  - 画幅 -> 映射为接近的 `size`
  - 不支持的字段静默降级

## 价值

- UI 不再绑定单一供应商心智
- 后续接入其他厂商时，优先改网关适配，不需要推翻前端面板
