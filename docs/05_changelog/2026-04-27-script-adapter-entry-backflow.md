# 2026-04-27 内容创作入口返回链路修正

## 这次做了什么

修正内容创作模块的返回行为：

- 当用户从主 Chat 直接进入 `项目素材库` 或 `内容制作工作台` 时，返回按钮现在会直接回到 Chat
- 当用户先进入内容创作首页，再从首页内部继续进入二级页面时，返回按钮仍然回到内容创作首页

## 代码改动

- 更新 `src/modules/script-adapter/ScriptAdapterApp.tsx`
  - 根据 `initialScreen` 判断当前是否为“从 Chat 直接进入”
  - 为 `library` 与 `workspace` 统一使用动态返回处理
  - `项目素材库` 页的返回文案也会跟随入口变化

## 修复结果

解决了“从 Chat 点进项目素材库，却被返回到内容创作首页”的路径割裂问题，让入口和返回保持一致。
