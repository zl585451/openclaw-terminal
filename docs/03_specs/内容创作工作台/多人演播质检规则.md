# 多人演播质检规则

## 文档状态

- 版本：v1.0
- 状态：当前定版，可作为质检 Agent 的默认执行基线
- 生效方式：即日起默认按本规则执行，后续结合样章、录制反馈和成片效果迭代
- 修订原则：先保证底线一致，再逐步细化评分和返工策略

---

## 1. 文档目的

本文档用于定义多人演播有声小说在“文本口语化改编”和“演播设计标注”完成之后的统一质检规则，供质检 Agent、人工审校、导演复核和后期验收共同遵循。

本文档关注的核心问题不是“怎么改”，而是“改得对不对、稳不稳、能不能直接进入下一步”。

其核心目标如下：

1. 检查文本改编结果是否忠实原文、适合口播且便于演绎。
2. 检查演播设计结果是否克制、可执行、服务叙事而不抢戏。
3. 输出统一的质检结论、问题等级和返工建议，形成稳定闭环。

---

## 2. 适用范围

本文档适用于以下场景：

- 对口语化改编后的章节、场景、段落进行质量审核。
- 对演播设计 Agent 输出的音效、BGM、情绪、气口、声场标注进行审核。
- 对多人演播脚本在进入录制前进行综合验收。
- 对 Agent 自动输出进行批量质检与打回。

本文档不适用于以下场景：

- 原始小说创作质量评价。
- 演员实际表演优劣评价。
- 混音成片工程参数评审。
- 影视剧本结构改编评估。

---

## 3. 总原则

### 3.1 一句话原则

**质检只看结果是否合格，不替代改写；先守底线，再看质量；先发现问题，再给建议。**

### 3.2 四项核心要求

1. **客观**
   判断必须基于原文、改编文本和演播标注的实际差异，不凭主观喜好。
2. **分级**
   问题必须区分严重程度，不能所有问题一视同仁。
3. **可返工**
   每条问题应尽量指出原因、位置和修正方向。
4. **可闭环**
   质检结论应能直接支持“通过 / 修改后通过 / 打回重做”。

---

## 4. 质检 Agent 的职责边界

### 4.1 质检 Agent 负责

1. 对照原文检查改编结果是否失真。
2. 检查文本是否适合口播和多人演播。
3. 检查演播标注是否越权、过密或不可执行。
4. 输出问题清单、风险等级、结论和返工建议。

### 4.2 质检 Agent 不负责

1. 直接重写整段正文。
2. 擅自补写剧情。
3. 擅自改变演播风格基调。
4. 以个人偏好替代既定规则。

### 4.3 与其他 Agent 的关系

1. 文本改编 Agent 负责“改”。
2. 演播设计 Agent 负责“标”。
3. 质检 Agent 负责“查”。

质检 Agent 可以提出修改建议，但不应越过前两层直接改动内容定义。

---

## 5. 质检对象

质检时应同时检查以下三类输入：

1. 原文片段
2. 口语化改编文本
3. 演播设计标注结果

如三者缺一，质检结论必须标注为“上下文不足”或“仅做局部检查”。

---

## 6. 问题等级定义

建议统一使用三档问题等级。

### 6.1 P0 严重问题

一旦出现，原则上必须打回重做。

包括但不限于：

1. 改动关键剧情事实。
2. 改动人物关系、时间线、案件逻辑。
3. 提前泄露真相或伏笔。
4. 角色说出当前不可能知道的信息。
5. 演播标注明显暗示后文未揭示内容。
6. 文本已不适合作为同一章节的忠实改编。

### 6.2 P1 重要问题

不一定全盘打回，但必须修改后才能进入下一步。

包括但不限于：

1. 旁白仍明显书面化、朗读发涩。
2. 对白失真，不像人物真实会说的话。
3. 角色口吻混同，辨识度不足。
4. 场景切换不清，听众容易迷路。
5. 演播设计过密、抢戏或难落地。
6. BGM、音效、情绪标注与剧情情绪明显不匹配。

### 6.3 P2 优化问题

可修改可不修改，不影响进入下一步，但应记录。

包括但不限于：

1. 某些句子仍可更顺口。
2. 某些标注略显保守或略显重复。
3. 个别停顿、重音、声场提示还可更精细。
4. 节奏细部仍有优化空间。

---

## 7. 文本改编质检规则

### 7.1 忠实度检查

重点检查：

1. 是否改变剧情事实。
2. 是否改变信息顺序。
3. 是否删掉关键线索。
4. 是否提前解释原文未明说内容。
5. 是否改动人物动机、立场或视角重心。

### 7.2 可听度检查

重点检查：

1. 是否仍有过长复句。
2. 是否存在一听难懂的复杂指代。
3. 是否需要靠回看文本才能理解。
4. 是否存在明显书面连接词堆叠。
5. 是否有不自然的朗读断点。

### 7.3 人物度检查

重点检查：

1. 角色语言风格是否稳定。
2. 主要角色是否听起来彼此区分明显。
3. 是否全员同一种腔调。
4. 是否为了口语化损伤人物身份感。

### 7.4 连贯度检查

重点检查：

1. 旁白与对白是否顺滑衔接。
2. 场景转换是否清楚。
3. 情绪承接是否自然。
4. 是否存在突兀跳切。

---

## 8. 演播设计质检规则

### 8.1 叙事服从度检查

重点检查：

1. 是否越权改义。
2. 是否无依据补音、补情绪、补暗示。
3. 是否用演播层替代正文叙事。
4. 是否喧宾夺主。

### 8.2 可执行度检查

重点检查：

1. 标注是否清晰具体。
2. 是否存在抽象空话。
3. 是否便于 CV、导演、后期直接理解。
4. 字段命名和标签是否稳定。

### 8.3 节制度检查

重点检查：

1. 音效是否过多。
2. BGM 是否过满。
3. 情绪标注是否逐句堆满。
4. 气息、停顿是否标注过密。
5. 是否因过度设计削弱自然感。

### 8.4 连贯度检查

重点检查：

1. 声场切换是否合理。
2. 情绪曲线是否平顺。
3. 音乐切换是否顺。
4. 场景开合是否有听觉逻辑。

---

## 9. 一票否决项

以下问题出现任意一条，即默认不能通过：

1. 改编文本改变原文关键事实。
2. 提前泄露关键悬念。
3. 对白让角色知道其当前不该知道的信息。
4. 演播设计用音效或 BGM 暗示真相。
5. 标注密度高到明显影响阅读、执行或后续制作。
6. 输出结构混乱，无法进入下游流程。

---

## 10. 质检流程规范

### 10.1 第一步：建立对照组

质检前必须对齐：

1. 原文范围
2. 改编文本范围
3. 演播设计范围

不得用不完整上下文做完全结论。

### 10.2 第二步：先查底线

优先检查：

1. 是否失真
2. 是否泄露
3. 是否越权
4. 是否结构不可用

只要触发一票否决项，应优先输出打回结论。

### 10.3 第三步：再查质量

按以下顺序检查：

1. 忠实度
2. 可听度
3. 人物度
4. 连贯度
5. 可执行度
6. 节制度

### 10.4 第四步：形成问题清单

每条问题建议至少包含：

1. 问题等级
2. 问题位置
3. 问题描述
4. 影响说明
5. 修改建议

### 10.5 第五步：输出结论

质检结论统一分为三类：

1. `通过`
   无 P0、P1，仅存在少量 P2。
2. `修改后通过`
   无 P0，但存在 P1，需要定向修正。
3. `打回重做`
   存在 P0，或 P1 数量过多导致整体不可用。

---

## 11. 评分标准

建议按六项评分，每项满分 5 分。

### 11.1 忠实度

- 5 分：严格忠实原文，无事实偏移。
- 3 分：整体忠实，但局部表达存在轻微风险。
- 1 分：出现实质性误改或泄露。

### 11.2 可听度

- 5 分：自然顺口，基本可直接朗读。
- 3 分：主体顺畅，局部仍有发涩句。
- 1 分：明显仍是书面文。

### 11.3 人物度

- 5 分：主要角色区分清晰、稳定。
- 3 分：部分角色可辨，其余趋同。
- 1 分：角色普遍同腔同调。

### 11.4 连贯度

- 5 分：旁白、对白、转场、情绪承接完整。
- 3 分：主体连贯，局部稍硬。
- 1 分：明显割裂、跳切。

### 11.5 演播可执行度

- 5 分：标注清楚，便于直接进入导演和后期流程。
- 3 分：基本可用，但有模糊标注。
- 1 分：标注抽象或混乱。

### 11.6 节制度

- 5 分：增强充分但不过度。
- 3 分：局部偏满或偏保守。
- 1 分：明显抢戏或明显无效。

---

## 12. 推荐输出格式

质检 Agent 输出时，建议采用以下结构：

1. 质检范围
   标记原文和改编内容的对应区间。
2. 结论
   通过 / 修改后通过 / 打回重做。
3. 总评分
   六项评分及总评。
4. 关键问题
   优先列出 P0、P1，按严重程度排序。
5. 优化建议
   列出 P2 或后续增强建议。
6. 备注
   标记上下文不足、待人工确认项或保留意见。

## 14. 推荐判定策略

为避免尺度漂移，建议按以下策略执行：

1. 先保守，不轻易放过底线问题。
2. 对风格问题保持适度宽容，但要记录。
3. 对结构和事实问题保持严格。
4. 不因“整体感觉不错”而忽略具体硬伤。
5. 不因“个别小瑕疵”而否定整体合格结果。

---

## 15. 一句话执行准则

如果需要把本规则压缩成 Agent 执行口令，可使用以下版本：

**对照原文、口语化改编文本和演播设计标注，检查其是否忠实、可听、可演、可执行且不过度；优先识别事实偏移、提前泄露、角色失真、转场混乱和演播越权问题，并输出分级问题、评分与通过结论。**

---

## 16. 当前定版使用建议

在系统初期阶段，建议将本规则作为统一质检基线。

执行时遵循以下策略：

1. 先用同一尺度检查所有样章，积累稳定案例。
2. 先把 P0、P1 判定标准跑稳，再逐步细化 P2 优化项。
3. 当质检结果与人工判断持续偏差时，再回头微调规则。
4. 后续如需加入题材特化规则，应在本规范之上叠加，不替换底线项。
