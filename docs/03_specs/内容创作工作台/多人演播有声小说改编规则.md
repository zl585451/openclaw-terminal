# 多人演播有声小说改编规则

## 文档状态

- 版本：v1.0
- 状态：当前定版，可作为文本口语化改编 Agent 的默认执行基线
- 生效方式：即日起默认按本规则执行，后续结合样章和成片反馈迭代
- 修订原则：不动底线、逐步细化、以实际演播效果为准

---

## 1. 文档目的

本文档用于定义小说文本改编为多人演播有声小说时的统一规则，供人工编辑、Agent 改编链路、质检流程共同遵循。

本规则的核心目标有三个：

1. 在不改变原著总体大纲和关键内容的前提下完成口语化改编。
2. 让旁白和角色台词更适合朗读、演播与后期制作。
3. 提升多人配音场景中的信息清晰度、情绪连贯性和角色区分度。

---

## 2. 适用范围

本文档适用于以下场景：

- 悬疑、刑侦、都市、现实向小说的有声化改编。
- 从书面小说改写为多人演播脚本前的预处理。
- Agent 对章节、场景、段落进行自动改编时的规则约束。
- 对改编结果进行人工审核、返工和质量评分时的检查基准。

本文档不适用于以下场景：

- 大纲重写。
- 影视化改编。
- 戏剧结构重组。
- 明显增删剧情的再创作版本。

---

## 3. 核心改编原则

### 3.1 总原则

多人演播改编的基本原则是：

**只改表达，不改事实；只改听感，不改结构；只改说法，不改剧情。**

### 3.2 四项核心要求

1. **忠实原文**
   保留原作的剧情、信息顺序、人物关系、案件逻辑和情绪走向。
2. **适合口播**
   改成适合耳朵接收、适合演员说出口、适合听众一次性理解的语言。
3. **便于演绎**
   给旁白和 CV 留出明确的停顿点、情绪承接点、转场点。
4. **保持连续**
   让章节内、场景间、人物对话之间的衔接更加自然，避免“书面感断裂”。

---

## 4. 不可变更的底线规则

以下内容为硬约束，任何 Agent 或人工编辑均不得突破：

1. 不改变小说总体大纲。
2. 不新增关键剧情、关键线索、关键人物关系。
3. 不删减对案件推进、人物命运、主线悬念有影响的信息。
4. 不更改时间线、地点关系、人物身份、事件因果。
5. 不提前泄露原文尚未揭示的真相。
6. 不把原本含蓄的伏笔改写成直接解释。
7. 不把人物立场、人物动机改写成与原文相反或明显偏离。
8. 不把叙事重心从原章节主视角随意切换到其他角色。
9. 不为了“口语化”而降低悬疑感、压迫感、真实感。
10. 不把小说改写成短视频文案、营销文案或说书腔过重的文本。

---

## 5. 语言改编规则

### 5.1 句式规则

1. 长句拆短句。
2. 连续复句拆为多个清晰信息块。
3. 避免一整句承载过多时间、地点、动作、心理、结论。
4. 优先使用主谓宾明确的句子。
5. 当原句包含多重修饰语时，应保留核心信息，弱化堆叠修饰。

### 5.2 口语化规则

1. 将明显书面化表达改为自然口语表达。
2. 保留叙事气质，不可过度网络化、口头禅化、喜剧化。
3. 允许补出必要主语、宾语或指代对象，避免听众听丢。
4. 连接词应以自然衔接为主，减少“然而、继而、随后、因此”等纯书面连接。
5. 一段内如果信息密度过高，应通过停顿句、转接句、动作句分层输出。

### 5.3 听感优先规则

1. 改写后的句子必须能被一次听懂。
2. 听众不能依赖“回看上一句”才能理解。
3. 同一句中如存在多个“他、她、那个人、对方”等指代，应尽量消除歧义。
4. 重要信息前后应留出缓冲句，避免听觉拥堵。

---

## 6. 旁白改编规则

### 6.1 旁白职责

旁白主要承担以下功能：

1. 交代时间、地点、场景变化。
2. 补足对白无法自然表达的信息。
3. 控制悬疑节奏与气氛推进。
4. 承接人物动作、情绪和转场。

### 6.2 旁白写法要求

1. 旁白语言应清楚、稳当、易听，不追求过度文学化堆砌。
2. 一段旁白优先只完成一个主要任务。
3. 环境描写应服务气氛和剧情，不可长篇停滞。
4. 心理描写优先外化为动作、语气、反应。
5. 场景结束前，旁白应尽量给出明确的情绪收束或悬念挂点。

### 6.3 旁白禁忌

1. 不连续堆叠抽象形容词。
2. 不长段解释角色内心而缺少可演绎支点。
3. 不用旁白替角色”说完所有结论”。
4. 不反复解释听众已经能从对白中得到的信息。

### 6.4 旁白与内心独白的区分（演播口径）

以下全部默认是旁白，由旁白CV读，不进入角色CV出场：

- `她心里忽然有点发紧。`
- `她隐约觉得屋里不太对。`
- `她脑子里全是那些纸页。`
- `她感觉掌心传来一丝震动。`
- `她想起昨晚那通电话。`

这些是叙述者在描述角色动作、身体感受、心理状态，不是角色”说出来”或”脑内直接发声”，应归旁白。

**只有可作为脑内原声播放的直接念头才允许 `inner_monologue`**：

允许：
- `内心:周佳宁|不对，屋里有人来过。`
- `内心:周佳宁|这箱子不能丢。`

不允许（应归旁白）：
- `内心:周佳宁|她心里忽然有点发紧。`
- `内心:周佳宁|她脑子里全是那些纸页。`

---

## 7. 角色台词改编规则

### 7.1 总体要求

角色台词必须满足两个标准：

1. 像真人会说出来的话。
2. 能让不同角色之间听起来有区分。

### 7.2 角色区分规则

每个主要角色应建立稳定的话语模型，包括：

1. 常用词汇风格。
2. 句长习惯。
3. 情绪表达方式。
4. 信息表达顺序。
5. 身份对应的语气特征。

例如：

- 警察角色更偏结论导向、追问导向。
- 证人角色可能更犹豫、绕弯、补充细节。
- 家属角色更容易情绪波动、重复、打断。
- 老年角色和青年角色在词汇与句速感上应有差异。

### 7.3 台词改写要求

1. 避免整段台词像书面陈述报告。
2. 信息量过大的说明句，可拆为追问式、应答式、反应式对白。
3. 冲突场景可使用短句、断句、打断句。
4. 情绪场景允许出现停顿、改口、吞句，但不应失真。
5. 角色说话不得全部统一成播音腔或统一成同一种口头表达。

### 7.4 台词禁忌

1. 不把人物全部改成”高情商解释型”对话。
2. 不把悬疑台词改得过于直白。
3. 不让角色说出其当前不可能知道的信息。
4. 不因口语化而破坏人物身份感。

### 7.5 对白与角色动作的区分（演播口径）

**只有角色真正说出口的话才是对白。**

判断对白的硬标准：
- 原文有引号里的话
- 或明确出现”说、问、喊、低声道、应了一声”等发声动作动词

以下全部是旁白，不是对白：
- `旁白|她伸手拿起对讲机。`（不是 `周佳宁|她伸手拿起对讲机。`）
- `旁白|周佳宁把钥匙插进锁孔，拧了两圈。`
- `旁白|箱子不算重。`（不是 `周佳宁|箱子不重。`）

**角色动作永远不是对白**。所有角色动作（推门、拿起、放下、站、坐、躺、伸手、低头、转身）必须写成旁白。

## 8. 场景与转场规则

### 8.1 场景结构建议

每个演播场景建议至少包含以下要素中的三项以上：

1. 起场信息
   时间、地点、人物、氛围。
2. 动作推进
   谁进入、谁发现、谁开口、谁打断。
3. 信息推进
   线索、冲突、判断、误导、转折。
4. 情绪落点
   紧张、迟疑、崩溃、压抑、回稳、留白。
5. 结尾钩子
   为下一场保留追听动力。

### 8.2 转场要求

1. 场景切换必须有明确提示。
2. 时间切换要让听众立即感知。
3. 空间切换要避免听觉迷路。
4. 回忆、插叙、现实线切换时必须增强提示语。
5. 转场不能只靠空行或语义暗示，须有可听化标记。

### 8.3 多角色场景要求

1. 对话参与人数较多时，应定期插入短旁白校正人物位置和动作。
2. 连续多轮对白后，要提醒当前主导者或空间变化。
3. 不可连续出现多个“他说、她说”而不标清身份。
4. 当同场角色声音特征接近时，文本需提供更明显的身份支撑。

---

## 9. 节奏与情绪规则

### 9.1 节奏控制

1. 调查推进段应以清晰和效率优先。
2. 情绪段应给出喘息和停顿空间。
3. 悬疑段应保留延迟揭示，不抢节奏。
4. 大段说明信息应穿插动作、反应、追问，避免平铺直叙。

### 9.2 情绪承接

1. 场景内部情绪转折必须有触发点。
2. 角色从冷静到激动、从压抑到崩溃，文本应给出可演信号。
3. 段落之间应照顾上一句的情绪余波，避免硬切。
4. 章节开头应尽快进入状态，章节结尾应形成追听点。

---

## 10. 信息保真规则

### 10.1 必须保留的信息

1. 案件事实。
2. 线索来源。
3. 人物身份信息。
4. 时间先后关系。
5. 重要情绪节点。
6. 伏笔位置与揭示顺序。

### 10.2 可调整的信息

1. 句式长度。
2. 段落拆分方式。
3. 旁白与对白的分配比例。
4. 非关键修饰语的表达方式。
5. 局部重复表达的压缩与顺序微调。

### 10.3 严禁误改的信息

1. 因果关系。
2. 侦查逻辑。
3. 证据指向。
4. 人物立场。
5. 关键时间点。
6. 章节悬念层级。

---

## 11. Agent 改编流程规范

为避免一步改写导致跑偏，建议 Agent 采用分层流程。

### 11.1 第一步：剧情锁定

先提取本章不可改信息表，至少包含：

1. 角色名单。
2. 时间地点。
3. 关键事件。
4. 关键线索。
5. 情绪主线。
6. 伏笔与保密点。

### 11.2 第二步：场景切分

将章节拆成适合演播的场景单元，建议按以下依据切分：

1. 时间变化。
2. 地点变化。
3. 在场人物变化。
4. 叙事目的变化。
5. 情绪段落变化。

### 11.3 第三步：角色标注

对每个场景标注：

1. 主导角色。
2. 信息提供角色。
3. 情绪承接角色。
4. 旁白承担的信息范围。

### 11.4 第四步：口语化改写

按本规范完成改写，要求：

1. 先改旁白，再改对白。
2. 先保清晰，再求气质。
3. 每次改写后对照剧情锁定表检查偏移。

### 11.5 第五步：演播质检

质检时至少检查以下项目：

1. 是否改变原剧情事实。
2. 是否存在提前泄露。
3. 是否有角色口吻混同。
4. 是否有听感拗口的长句。
5. 是否存在场景切换不清。
6. 是否有旁白过满、对白过满或节奏失衡。

## 12. 质量评分标准

建议将改编结果按四个维度评分，每项满分 5 分。

### 12.1 忠实度

- 5 分：剧情、信息、伏笔、情绪完全对齐原文。
- 3 分：主体保留，但局部表述造成轻微偏差。
- 1 分：出现明显删改、误改或提前泄露。

### 12.2 可听度

- 5 分：整体顺畅，几乎可直接进入录制。
- 3 分：基本可听，但存在局部长句、信息拥堵。
- 1 分：明显仍是书面文，读出来发涩。

### 12.3 人物度

- 5 分：主要角色说话习惯稳定、清晰可辨。
- 3 分：少量角色有区分，其余角色趋同。
- 1 分：角色口吻混杂，缺乏辨识度。

### 12.4 连贯度

- 5 分：旁白、对白、转场、情绪承接完整顺滑。
- 3 分：主体连贯，但局部存在跳切或断裂。
- 1 分：整体像拼接文本，演播衔接困难。

---

## 13. 推荐输出结构

当 Agent 输出某一章或某一场的改编结果时，推荐采用以下结构：

1. 原文范围
   标记本次处理的章节或段落范围。
2. 剧情锁定摘要
   简述不可改信息点。
3. 改编正文
   输出口语化后的旁白与对白文本。
4. 质检备注
   标注潜在风险、伏笔保留点、待人工复核点。

---

## 14. 一句话执行准则

如果需要把本规则压缩成 Agent 的执行口令，可使用以下版本：

**将小说书面文本改写为适合多人演播的口语化文本；保持剧情、大纲、线索、人物和情绪走向不变；优先提升旁白流畅度、角色可演性、听觉清晰度和场景衔接感；严禁提前泄露、严禁改动因果、严禁把文本改成说书稿或营销文案。**

## 16. 当前定版使用建议

在系统初期阶段，建议将本规则作为文本改编层的统一默认规范。

执行时遵循以下策略：

1. 先保证忠实原文和可听度，不急于追求风格花样。
2. 每次只解决一个主要问题，例如句式、旁白、角色区分或转场。
3. 若某条规则与原文悬疑节奏冲突，优先保护原文信息层级。
4. 后续如需题材细分，应在本规则之上叠加，不替换底线约束。
