# 多人演播演播设计规则

## 文档状态

- 版本：v1.0
- 状态：当前定版，可作为演播设计 Agent 的默认执行基线
- 生效方式：即日起默认按本规则执行，后续在真实项目跑通后迭代修订
- 修订原则：小步更新、保留兼容、先验证再扩展

---

## 1. 文档目的

本文档用于定义多人演播有声小说在完成文本口语化改编之后的演播设计规则，供演播设计 Agent、人工导演、后期制作和质检流程共同遵循。

本文档关注的不是“说什么”，而是“怎么说、怎么配、怎么听”。

其核心目标如下：

1. 在不改动正文剧情和事实信息的前提下，为文本补充可执行的演播设计标注。
2. 统一音效、BGM、CV 情绪、气息、停顿、声场和动作感的使用边界。
3. 让多人演播的成片在听感上更稳定、更连贯、更具沉浸感。

---

## 2. 适用范围

本文档适用于以下场景：

- 已完成口语化改编的小说文本。
- 多人有声剧、有声小说、剧情化广播稿的演播层设计。
- Agent 自动为脚本生成音效、BGM 和演绎标注的流程。
- 对演播标注结果进行人工审核与后期落地时的统一标准。

本文档不适用于以下场景：

- 正文剧情改写。
- 大纲重构。
- 配乐制作细节参数设计。
- 录音棚工程级混音手册。

---

## 3. 总原则

### 3.1 一句话原则

**演播设计只做增强，不做改写；只加演法，不改内容；只服务叙事，不喧宾夺主。**

### 3.2 四项核心要求

1. **不越权**
   演播设计层不得更改剧情事实、对白内容、信息顺序和悬念层级。
2. **可执行**
   所有标注都应明确、简洁，便于 CV、导演和后期理解与落地。
3. **有节制**
   音效、BGM、情绪标注应服务剧情，不得堆满、抢戏或制造噪音。
4. **保连贯**
   场景内部和场景之间的声场、情绪、气口应自然承接。

---

## 4. 与文本改编 Agent 的职责边界

为避免多 Agent 串扰，需明确职责分层。

### 4.1 文本口语化改编 Agent 负责

1. 书面文转口播文。
2. 旁白顺滑化。
3. 台词可演化。
4. 场景叙事衔接。

### 4.2 演播设计 Agent 负责

1. 音效建议。
2. BGM 状态设计。
3. CV 情绪强度标注。
4. 气息、停顿、重音建议。
5. 动作感和声场建议。
6. 场景开合的听感组织。

### 4.3 演播设计 Agent 不得负责

1. 改写剧情。
2. 增删对白。
3. 提前解释伏笔。
4. 改动人物设定。
5. 擅自增加原文不存在的重要事件。

---

## 5. 不可突破的底线规则

1. 不修改正文事实信息。
2. 不修改案件逻辑、人物关系、时间线和悬疑顺序。
3. 不用音效或 BGM 暗示正文尚未揭示的真相。
4. 不用过强的演播提示替代角色表演和旁白叙事。
5. 不以“氛围感”为由添加无依据的音效事件。
6. 不让 BGM 情绪与剧情情绪相冲突。
7. 不让演播层输出变成过密导演分镜，导致文本失去自然性。
8. 不把演播标注写成不可执行的抽象评价，例如“更有灵魂”“再宿命一点”。

---

## 6. 演播设计的六个维度

演播设计 Agent 的输出建议围绕以下六个维度展开：

1. 音效
2. BGM
3. CV 情绪
4. 气息与停顿
5. 动作感
6. 声场与空间

---

## 7. 音效设计规则

### 7.1 音效职责

音效主要用于：

1. 强化空间真实感。
2. 提示动作发生。
3. 帮助场景切换。
4. 承托悬疑和情绪节奏。

### 7.2 音效使用原则

1. 音效必须对应文本中真实存在或可合理感知的动作与环境。
2. 优先使用关键音效，不追求“全景填满”。
3. 一个场景内应有主次，不可所有动作都加音效。
4. 关键音效优先服务剧情信息而不是热闹感。
5. 悬疑音效应克制，避免廉价惊悚化。

### 7.3 常见音效类别

1. 环境音
   风声、楼道回响、夜市噪声、雨声、电流杂音、空屋混响。
2. 动作音
   脚步、推门、翻页、拖拽、落灰、开关、按键、碰撞。
3. 物件音
   锁芯转动、箱扣弹开、手铐轻碰、对讲机摩擦、电池仓开合。
4. 转场音
   空气感变化、环境底噪切换、远近景变化、电话接通质感。

### 7.4 音效标注要求

1. 标清音效来源。
2. 标清是否前景音效或背景音效。
3. 标清是否一次性触发或持续存在。
4. 必要时标清强弱和远近。

示例：

- `SFX: 门锁发涩转动，近景，一次性，短`
- `SFX: 楼道脚步回响，由近到远`
- `SFX: 翻页声，近景，连续但轻`
- `AMB: 老屋静态底噪，轻微空荡感，持续`

### 7.5 音效禁忌

1. 无依据补音。
2. 每句都加音效。
3. 为制造戏剧性而夸大动作音。
4. 在高信息密度段加入抢注意力的复杂音效。

## 8. BGM 设计规则

### 8.1 BGM 职责

BGM 的作用是：

1. 提供情绪底色。
2. 协助场景开合。
3. 承接悬念与情绪变化。
4. 在不打断文本理解的前提下增强沉浸感。

### 8.2 BGM 使用原则

1. BGM 必须服从旁白和对白。
2. 有信息密度的段落，BGM 应简而稳。
3. 悬疑段可低频、稀疏、压抑，不应过满。
4. 情绪爆发段可增强张力，但应给人声留空间。
5. 重要揭示前后允许短暂留白或弱化音乐。

### 8.3 常见 BGM 状态标签

建议使用有限状态标签，而不是无限发散描述：

1. `无音乐`
2. `轻悬疑`
3. `压抑潜流`
4. `空屋静场`
5. `调查推进`
6. `回忆朦胧`
7. `情绪压低`
8. `紧张收束`
9. `短促惊疑`
10. `尾钩留白`

### 8.4 BGM 切换规则

1. 场景开头先确定底色，再决定是否入乐。
2. 对话密集段尽量少切换。
3. 情绪转折点才允许切换音乐状态。
4. 小转折优先通过音量、配器、留白处理，不必每次换曲。
5. 章节结尾要么收束，要么留钩，但不应硬顶。

### 8.5 BGM 禁忌

1. 全程铺满。
2. 用过于明显的惊悚素材强行制造情绪。
3. 先于剧情泄露恐怖、真相或反转。
4. 频繁起落打断叙事节奏。

## 9. CV 情绪设计规则

### 9.1 情绪标注目标

情绪标注的目标不是替演员表演，而是提供边界和方向。

一个合格的情绪标注，应回答以下问题：

1. 当前情绪基调是什么。
2. 情绪强度到什么程度。
3. 是外放还是内收。
4. 这一句和上一句相比，是升、平还是降。

### 9.2 情绪强度建议

建议使用 5 档强度，避免无穷细分：

1. `1级` 极轻，几乎不外露。
2. `2级` 轻微，有感但克制。
3. `3级` 中等，听众能明显感知。
4. `4级` 较强，情绪压住理性边缘。
5. `5级` 爆发，接近失控或强冲突。

### 9.3 常见情绪标签

1. 克制
2. 冷静
3. 迟疑
4. 紧绷
5. 压抑
6. 疲惫
7. 警惕
8. 惊疑
9. 失神
10. 激动
11. 崩溃边缘
12. 强硬

### 9.4 情绪标注规则

1. 每句只标一个主情绪，必要时补一个次情绪。
2. 情绪必须和剧情触发点对应。
3. 同一人物在短时间内不可频繁大跳档。
4. 悬疑刑侦题材优先克制型情绪，不宜动辄外放。
5. 高张力情绪出现越少，越有效。

示例：

- `EMO: 克制/2级`
- `EMO: 惊疑/3级，尾音收住`
- `EMO: 压抑/2级 -> 紧绷/3级`

## 10. 气息、停顿与重音规则

### 10.1 设计目标

气息和停顿用于帮助 CV 找到听觉节奏，不是把表演机械切碎。

### 10.2 气息标注原则

1. 只在关键句、转折句、情绪承接句标注。
2. 不逐字逐句标满呼吸。
3. 以自然气口为基础，不制造不合理断句。
4. 情绪越克制，气息标注越要轻。

### 10.3 常见气息与停顿标签

1. `短停`
2. `停顿`
3. `微吸气`
4. `压气`
5. `缓出气`
6. `尾音收住`
7. `重读`
8. `放轻`

示例：

- `BREATH: 句首微吸气，句中短停`
- `PAUSE: “十七”前停顿半拍`
- `STRESS: 重读“空的”`

### 10.4 使用场景

1. 发现关键物件前后。
2. 情绪突然收紧处。
3. 重要数字、案号、姓名出现处。
4. 回忆切入或现实回落处。
5. 章节尾钩处。

### 10.5 禁忌

1. 过度精细标注到影响自然表演。
2. 每句都加“停顿”“吸气”。
3. 为追求戏剧性而强行拖长尾音。

---

## 11. 动作感设计规则

### 11.1 定义

动作感不是新增动作，而是让文本中已有动作在声音层面更可感。

### 11.2 动作感来源

1. 发声位置变化。
2. 语速变化。
3. 轻微身体带动气息。
4. 与音效协同的动作反应。

### 11.3 标注范围

动作感可用于提示：

1. 转身说话。
2. 走动中说话。
3. 蹲下、起身、靠近、后退。
4. 低头、抬眼、贴近物件。
5. 突然停住、动作僵住。

示例：

- `MOVE: 走近后压低声音`
- `MOVE: 蹲下查看，句尾发力减弱`
- `MOVE: 动作停住，再开口`

### 11.4 禁忌

1. 用动作感代替情绪表达。
2. 在静场里频繁制造身体动态。
3. 写成影视镜头说明而不是声音提示。

---

## 12. 声场与空间规则

### 12.1 设计目标

声场标注用于帮助后期与 CV 理解“声音在什么空间里发生”。

### 12.2 常见声场标签

1. 近景
2. 中景
3. 远景
4. 室内空屋混响
5. 楼道回声
6. 室外街噪底
7. 电话质感
8. 对讲机失真质感
9. 贴耳低声
10. 远处回应

### 12.3 使用原则

1. 声场服务空间识别。
2. 声场变化应与场景切换同步。
3. 同场景内部只在必要时做近远切换。
4. 电话、对讲机、回忆等特殊声场应统一风格。

### 12.4 禁忌

1. 频繁切换远近，造成听觉疲劳。
2. 所有句子都标空间信息。
3. 特殊声场风格前后不一致。

## 13. 演播设计输出格式规范

建议演播设计 Agent 使用结构化输出，方便后续程序读取与人工审核。

### 13.1 场景级字段

每个场景建议包含以下字段：

- `scene_id`
- `scene_summary`
- `bgm_state`
- `ambient`
- `space`
- `pace`
- `emotion_curve`
- `notes`

### 13.2 行级字段

每条旁白或台词建议包含以下字段：

- `speaker`
- `text`
- `emo`
- `breath`
- `stress`
- `delivery`
- `move`
- `sfx`
- `mix_hint`

### 13.3 推荐示例

```yaml
scene_id: ch01_sc01
scene_summary: 周佳宁回到老房子，准备上阁楼收拾旧物
bgm_state: 空屋静场
ambient:
  - 楼道风声，轻
  - 老屋底噪，轻微空荡感
space: 室内空屋混响
pace: 慢起，逐步收紧
emotion_curve: 平静 -> 压低 -> 隐约不安
lines:
  - speaker: 旁白
    text: 三月的风，从楼道的窗户缝里灌进来。
    emo: 克制/1级
    breath: 句尾放轻
    delivery: 慢起，平稳
    sfx:
      - 风声，背景，持续
    mix_hint: 中近景
  - speaker: 周婉云
    text: 东西都搬得差不多了，就剩阁楼那些旧物。
    emo: 疲惫/2级
    breath: 句中短停
    delivery: 音量不高，略带气短
    mix_hint: 门口中景
```

## 14. Agent 执行流程规范

### 14.1 第一步：读取正文改编结果

先确认当前输入文本已经完成口语化改写，且剧情锁定信息完整。

### 14.2 第二步：识别场景目标

提取每场的：

1. 空间属性。
2. 情绪底色。
3. 信息密度。
4. 关键动作点。
5. 转折点。

### 14.3 第三步：分配演播元素

按“少而准”的原则分配：

1. 环境音。
2. 关键动作音。
3. BGM 状态。
4. CV 情绪强度。
5. 必要气口。
6. 特殊声场。

### 14.4 第四步：检查是否越权

逐项检查：

1. 是否改动了正文含义。
2. 是否添加了正文没有依据的事件。
3. 是否暗示了未来剧情。
4. 是否标注过密。

### 14.5 第五步：生成结构化输出

输出内容应便于：

1. 人工导演审阅。
2. 后期声音团队使用。
3. 下游程序解析。

## 15. 质量评分标准

建议按以下五项进行评分，每项满分 5 分。

### 15.1 叙事服从度

- 5 分：完全服务正文，不抢戏不越权。
- 3 分：主体服从，但局部提示偏多。
- 1 分：明显喧宾夺主或暗改叙事。

### 15.2 可执行度

- 5 分：标注清晰，CV 和后期可直接理解。
- 3 分：基本可用，但存在模糊表述。
- 1 分：抽象空泛，难以落地。

### 15.3 节制度

- 5 分：音效、BGM、情绪标注分寸稳定。
- 3 分：局部偏满，但不致影响整体。
- 1 分：明显堆砌，干扰叙事。

### 15.4 连贯度

- 5 分：声场、情绪、节奏承接自然。
- 3 分：局部切换略硬。
- 1 分：整体像散点拼贴。

### 15.5 沉浸度

- 5 分：能稳定增强临场感与画面感。
- 3 分：有一定增强，但记忆点不足。
- 1 分：增强效果弱，甚至出戏。

---

## 16. 一句话执行准则

如果需要把本规则压缩成 Agent 执行口令，可使用以下版本：

**在不改动正文剧情、信息顺序和悬念层级的前提下，为多人演播文本补充适度、清晰、可执行的音效、BGM、CV 情绪、气息、停顿、动作感和声场标注；一切设计以服务叙事、增强沉浸、保持连贯为目标，严禁抢戏、严禁越权、严禁过度标注。**

## 18. 当前定版使用建议

在后续 Agent 系统实际运行前，建议将本规则作为默认版本直接投入使用。

执行时遵循以下策略：

1. 先严格按本规则跑通完整链路，不预先加入过多例外分支。
2. 优先观察实际样章中的问题，再决定是否补充新标签或新字段。
3. 如需改动，优先新增兼容字段，不轻易推翻现有输出结构。
4. 当样本量足够后，再拆分题材特化版和高级词典版。
