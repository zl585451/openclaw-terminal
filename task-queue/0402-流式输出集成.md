# 流式输出集成到 OCT

## 需求
MiniMax API 支持流式输出（ SSE / Server-Sent Events），需要集成到 OCT Terminal。

## 关键参数

### 请求头
```python
headers = {
    "Authorization": f"Bearer {api_key}",
    "Content-Type": "application/json",
    "Accept": "text/event-stream"  # ← 关键：启用 SSE
}
```

### 请求体
```python
payload = {
    "model": "abab5.5-chat",
    "stream": True,  # ← 必须设为 True
    "messages": [{"role": "user", "content": "..."}]
}
```

### 响应格式
返回 SSE 格式，每个 chunk：
```
data: {"choices":[{"delta":{"content":"部分内容"}}]}
data: {"choices":[{"delta":{"content":"下一部分"}}]}
...
data: [DONE]
```

## 实现要点

1. **SSE 解析**：需要解析 `data: ` 前缀的文本行
2. **JSON 提取**：提取每个 chunk 中的 `choices[0].delta.content`
3. **流式渲染**：实时追加到思维链/输出面板，不要等全部完成
4. **DONE 信号**：收到 `data: [DONE]` 时结束

## ⚠️ 注意事项

- MiniMax Pro API (`/v1/text/chatcompletion_pro`) 的 `stream` 参数默认是 `False`
- WebSocket 方式可能更适合高频实时场景
- 需要处理连接断开、重试等情况
