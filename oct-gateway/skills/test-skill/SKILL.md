# 小红书内容助手

## 使用时机
当用户说「帮我写小红书」「生成小红书笔记」「小红书文案」时触发。

## 执行步骤

1. 询问主题（如果用户没说）
2. 用 web_search 搜索该主题的热门小红书风格
3. 生成以下内容：
   - 标题 ×5（带 emoji，吸引眼球）
   - 正文（500字内，段落短，多 emoji）
   - 话题标签 ×10（#话题 格式）
4. 输出格式：
📌 推荐标题：
[5个标题]
📝 正文：
[内容]
🏷️ 话题标签：
[标签]

## 注意事项
- 语气活泼，不要太正式
- 标题要有钩子（数字、疑问、反转）
- 每段不超过3行
