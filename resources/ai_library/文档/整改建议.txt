# AI.library 整改任务清单

## 整改优先级

### 第一优先：单例模式（解决启动慢问题）
文件：openclaw_tool.py
问题：AudioKnowledgeTool 每次实例化都重新加载 Embedding 模型，耗时约10秒
要求：将 KnowledgeBaseAPI 改为全局单例，整个进程生命周期只初始化一次
参考：使用模块级变量 + 懒加载模式实现

### 第二优先：API Key 安全问题
文件：openclaw_tool.py 第7行
问题：DeepSeek API Key 硬编码在代码里
要求：删除硬编码，改为纯环境变量读取，如果环境变量不存在则抛出明确错误提示

### 第三优先：分块参数调整
文件：audio_knowledge_base.py Config类
问题：CHUNK_SIZE=500 太小，专业术语上下文经常被切断
要求：CHUNK_SIZE 改为 800，CHUNK_OVERLAP 改为 150
注意：改完后需要重新运行 --full-pipeline 重建知识库

### 第四优先：QA生成提示词优化
文件：audio_knowledge_base.py QA生成相关方法
问题：使用通用提示词，缺少音频专业场景的提问角度
要求：在提示词中增加以下提问维度：
- 该参数/技术在广播剧场景下的具体应用
- 与同类方法/工具的对比
- 常见错误用法和避坑建议
- 不同风格/题材下的参数差异

## 完成后
重新运行完整流水线：
python audio_knowledge_base.py --full-pipeline
验证：用5个专业问题测试回答质量，记录置信度变化
